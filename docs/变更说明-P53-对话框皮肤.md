# 变更说明 · P53：对话框皮肤（可视化画布 + 贴图九宫格 + 导出成品）

> 日期：2026-11-15　状态：已落地并通过门禁（pytest 1030 passed / pyright 112=基线 / 覆盖率见 STATUS）

## 一、为什么改

看了「两分钟教你制作 galgame 对话框」那类教程：做法是**在 Ren'Py 里查 textbox 尺寸 → 去 Photopea
按固定尺寸裁一块画布 → 填色 / 加渐变蒙版 / 图案填充 → 导出 PNG → 覆盖 textbox**。

这套流程暴露出两个事实：

1. 对话框外观本质是**一张图**，引擎不该逼用户去调几十个数字滑杆；
2. 但「整张固定尺寸替换」有硬伤——面板尺寸或画布分辨率一变，图就要么被拉变形，要么回去重画。

如果 MYONL 只是把这件事照抄一遍，那它确实没有存在意义（Ren'Py 已经做完了）。

## 二、MYONL 的不同之处（做的不是同一件事）

| 别人的做法 | MYONL P53 |
|---|---|
| 固定尺寸 PNG 整张替换 | 同一张 PNG 按**九宫格**切片自适应：四角不拉伸，边与中段拉伸 → 任意宽高不变形 |
| 回 PS 加渐变蒙版 | 引擎内 `panel_fade` / `panel_fade_bottom` 直接算垂直 alpha 渐变 |
| 回 PS 做图案填充 | 引擎内 `panel_texture` + `panel_texture_alpha` 平铺纹理（自带无缝纸纹可平铺） |
| 只能改外观，位置/尺寸靠手改配置文件 | UI 设计器里**直接在画布上拖**：拖本体上下移动，拖上边缘改高度，松手即预览 |
| 做完只能自己用 | 「导出 textbox.png」把当前设计**导出成成品 PNG**，写进 `images/`，可直接当 `panel_image`，也能拿去给别的引擎 |
| 靠眼睛反复调 | 预设库一键套（极简无框 / 玻璃卡片 / 贴图九宫格 / 纸张纹理 / 电影字幕），先看到效果再微调 |

一句话：**MYONL 把「对话框」从"一张固定图"变成"一个自适应的皮肤层 + 可导出资产"**。

## 三、怎么用

### 3.1 编辑器里（推荐）

`游戏内 UI 设计 → 对话框皮肤`：

1. 点一个预设（第一次建议「贴图九宫格」，教程示例里已自带 `textbox.png` / `paper.png`）；
2. 需要自己的图：把 PNG 放进项目 `images/`，在「贴图（panel_image）」里填文件名（有素材下拉）；
3. 拖预览图上的对话框改位置/高度；九宫格四边按贴图四角圆角调整；
4. 「导出 textbox.png」→ 落到 `images/`，文件名可改。

### 3.2 配置文件里（等价写法）

```json
{
  "dialogue": {
    "default": {
      "panel_image": "textbox",
      "panel_slice": [28, 20, 28, 20],
      "panel_fade": 0,
      "panel_fade_bottom": 0,
      "panel_texture": "paper",
      "panel_texture_alpha": 40,
      "panel_tint": null,
      "panel_alpha": 235,
      "pad_x": 18,
      "pad_y": 10
    }
  }
}
```

- `panel_slice`：单值 = 四边同宽；`[左,上,右,下]` = 逐边。被夹在「四边之和 < 贴图尺寸」范围内。
- `panel_tint`：`[r,g,b]` 乘法染色（把别人的图改成自己主题色）；`null` = 不染。
- `pad_x` / `pad_y`：贴图后文字与面板边缘的额外内边距（名字行同步下移）。
- **所有键不填 = 引擎绘制的圆角/渐变面板，与旧版逐像素一致**（老工程零变化）。

## 六、已知限制

1. 皮肤只作用于 `default` 主对话框；NVL 整屏旁白仍用引擎渐变底（要做的话是同一套 `surface_for` 换个尺寸）。
2. 贴图走 `images/<名>.png` 解析，不支持 `images/子目录/`（与非皮肤素材规则一致）。
3. 面板缓存按「图片对象 + 尺寸 + 参数」做键，最多 8 份；热重载换图后键变化会重算，不会拿到旧图。
4. 拖拽只改「纵向位置 / 高度」；横向偏移与宽度仍走滑杆（避免一次改动太多参数导致画面漂移）。
