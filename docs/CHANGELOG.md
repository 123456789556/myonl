## 2026-11-19 · v1.2.8 · 底部按得到了

状态栏和导航栏是主动藏掉的（`hideBars()` 在窗口拿到焦点时收一次，从通知栏
拉回来还会再收），所以页面里 `env(safe-area-inset-bottom)` 拿到的基本是 0。
可**底部那根手势条不跟着藏** —— 它一直浮在页面最下面吃点击。页面自己留的
`calc(52px + 0)` 正好被它吃掉一条，五个 tab 最下面那部分看着在那儿，按了没反应。

改成在 Java 侧把 inset 算准，整块交给 WebView 当内边距：

- 顶部取 `max(systemBars.top, displayCutout.top)` —— 没刘海的机器栏藏了就是 0，
  顶到边正合适；有刘海/挖孔的是 cutout 高度，不会压住
- 底部取 `max(systemBars.bottom, systemGestures.bottom, displayCutout.bottom)`
  —— `systemGestures` 报的是手势区域，栏藏了它照样有效

页面里的 `env()` 还是 0，两段加起来刚好避开，不会叠两遍。

**这条只能你装上去按一下才能算验过**。我这边没有 Android SDK，编译不了也装不上；
CI 编过只证明代码是活的。

## 2026-11-19 · v1.2.7 · 手机上不再露出桌面按钮

设置中心顶部一直挂着「并排」—— 把页面怼到编辑区右边，左边继续写剧本。
桌面宽屏下有用；手机上屏宽连两栏都塞不下，点了不是没反应就是把本来就窄的
编辑区再切一半。旁边那句"调整后点保存即可，随时可关掉"也是桌面口吻。

现在屏宽小于 720 时这两个不生成。桌面不变。

这只是"手机上混着桌面控件"里查实的第一处。导出页的「并排」、问题面板的
「简单/详细」、预览的缩放条还在，得一个个看是不是手机真用得上，不一次全砍。

## 2026-11-19 · v1.2.6 · 素材库能看见了

素材页原来只有一块虚线框，写着「点这里选」。功能其实是通的 —— 安卓上点它就会弹
系统选择器，相册就在里面 —— 但没人猜得到那能开相册，等于没有。

现在框里有两个按钮：「从相册选图」「导入本地文件」。
点相册那个只让你挑图和视频（相册里本来也没有音频，混进去只会让人以为自己选错了）；
点本地文件那个，图、音频、视频、字体都能选。整块框照样能点，不用瞄准。

这是这版唯一的变化。README 另加了「现在还很糙的地方」一节，把目前确实不行的事
都列在明面上 —— 素材只验后缀名、素材是复制进工程所以占两份、素材卡片点不进去、
成品里玩家改不了台词、横屏两套导航还并存、场景页的浮动控件还压着输入框。

## 2026-11-19 · v1.2.5 · 那几个小按钮点得中了

游戏画面里那几个常驻小按钮（右上角的菜单、静音，右侧的存档、回顾、设置），
在手机竖屏上只有 26 像素见方，差不多小拇指指甲盖的一半。
以前要正正好好戳在中间才认，偏一点就被当成"点屏幕翻页"，翻过去一句台词。

现在外观一点没变，还是那么大、还是不吃画面，但手指落在它周围一圈都算数，
范围扩到 44 像素见方（手指舒服的最小尺寸）。两个键挨得近，落在中间那块重叠区，
算成离得近的那个 —— 不会想开菜单却静音了。

这个变化只在手指上能感觉到，截图看不出任何区别。

## 2026-11-19 · v1.2.4 · 试玩能退出来了

这一版只修"进得去出不来"，没有新功能。

问题有两层，之前只看到一层。

第一层：点「试玩示例」，编辑器是整页跳到游戏页的 —— 编辑器被游戏盖掉，
游戏里又没有回编辑器的路。现在改成在当前页里铺一层全屏试玩，顶部一条退出栏，
退出来还是刚才那个编辑器，进度都在。

第二层是真正让人骂的那层：安卓的物理返回键。
- 在编辑器页按返回，应用会**直接退出**，没保存的编辑全丢；
- 在游戏页按返回，只能在"菜单开／关"之间来回，**永远退不出去**。

现在返回键按层级逐层退：试玩层开着 → 关试玩层；在编辑器里 → 回作品列表；
游戏里 → 开菜单；在存档／设置／回顾子页 → 先回菜单，不是一下把面板整个关掉；
只有在作品列表或游戏标题页按返回，才是真的退出应用。

同时顺手修了三个小毛病：
- 标题页原来是"点哪都重新开始"，有存档的人手一偏就把自动档清掉、游戏重开。
  现在有存档时只有按钮能触发，「点哪都开始」只留给没存档的新人；
- 设置面板按 6 行留高、实际有 7 组，最后那组「对话框」被挤出面板底边，等于少一项；
- 竖屏的菜单／存档／设置抽屉底部间距写死 3%，全面屏的手势条会压住最后一行
  （菜单页是「回到标题」，存档页是「清空存档」）。改成跟着系统安全区走。

几条限制还是说清楚：
- 试玩的退出栏和游戏里那个「退出试玩」两个都在，看着有点重复 —— 前者是游戏卡死时的兜底；
- 正常发布出去的成品（单独 game.html）里没有这两个退出键，那是浏览器／APP 自己的事；
- 试玩时不再弹首次设置的三屏向导（玩家只是想看一眼），所以试玩里看不到那三屏；
- 启动 logo、开场动画、玩家向的新手关卡这一版都没做。

验收：全量 `1411 passed, 3 skipped`（退出码 0，本地实测 178.90s）；
类型检查 `engine/` 109 个错误（基线 112），棘轮通过。
试玩退出用真浏览器（Edge 360×800）跑了 9 条路径全过：入口出现、内嵌层、
编辑器未被覆盖、顶部退出、游戏内通知退出、标题页退出键、退出后入口仍可用、
伪造消息不会误关。

## 2026-11-19 · v1.2.3 · 改坏了能退回去

之前只有「撤销」，在内存里活，点关闭就没了；保存也是直接覆盖，没有历史。
做到一半改崩了、或者存错了一版，就真的没了。

现在每次保存前会自动把上一版留一份，存在设备里，关机也在。
「导出」页多了一个「历史版本（改坏了能退回去）」，
点开能看到这个作品每一版的修改时间和字数，点一下就退回去。
退之前还会把「现在这版」也存一份，点错了不至于连当前都没了。

几条限制说清楚：
- 内容没变不留，一分钟内连按只算一次，免得同内容堆几十份；
- 每个作品最多留 20 版，全局最多 60 版，超了丢最旧的；
- 快照放在独立的存储里，不占作品库的额度 —— 作品库只有 5MB，
  一张图就能撑爆，快照混进去会把正文一起挤坏。

顺带把导出页五个按钮分了主次：前两个（做成成品 / 打成 APK）是主线，给亮；
后三个（历史版本 / .gal / .json）是备份和回退，压暗。

另外这一版修了几处小毛病：
- 素材库顶栏四个按钮原来是文字符号（＋ / 网 / ⟳ / ⟩），渲染出来像乱码，换成线条图标；
- 顶栏和预览按钮上的 📦 ❓ 🎨 💾 ▶ 去掉，留纯文字；
- 素材页还写着「音频原样存」，其实 WAV 早就改成转 webm 了，改了文案。

验收：全量 `1401 passed, 3 skipped`（退出码 0，本地实测 210.87s）。
快照实测：连保存两次，设备里出现 2 条，能读回原文。

## 2026-11-19 · v1.2.2 · 首页不再是那张吃满屏的大卡

**只改界面，功能一个没动。**

以前首页第一张作品是整宽大卡：封面铺满、底部渐深、右下角一个「继续编辑」。
作品少的时候，那块蓝色渐变从顶部一直铺到屏幕尽头，下面「新建 / 导入」被压到底，
视觉重心全在一个空卡上——没封面时尤其明显，一张空卡比什么都重。

现在所有作品统一成横向小卡：左边封面方框，右边名字、指令数、素材数、修改时间。
一屏能看五六个，「新建 / 导入」自然跟在后面。作品只有一两个时，
列表按内容高度收起，不再撑满整屏留一大块空白。

底部导航换成单色线条图标（作品 / 新建 / 导入 / 设置）：SVG、1.4 线宽、跟随主题色。
不用 emoji —— emoji 自带颜色和字号，放工具栏里像贴纸，跟界面永远不是一套。
底部横排是图标加文字，看得清；侧边竖条以后只留图标，
56px 宽塞「设置」两字会挤成一团。

**这一版没做**：导航位置可选。那是改布局不是换皮，
横屏 360 高侧边一压就碰到标题，得连标题排版一起收拾。

验收：全量 `1401 passed, 3 skipped`（退出码 0，本地实测 163.20s）。

## 2026-11-19 · v1.2.1 · 视频真能放了，作品也能发给别人

**这一版三件事：一段真视频能进作品，成品能发给别人，平板横屏真的排成三栏。**

**一、真视频进「幕」。**
以前 `@video` 只能放一串连号图片，等于"看起来像视频的幻灯片"。现在手机相册里选一段真视频
（`@video 名 file`），原样进素材库，不压不转码；单文件上限 24 MB，超了会告诉你先在手机里剪短。
播放器同时只解一个视频：切幕、换背景、读档、退出立刻停、清、放；内存或核数不够的手机
自动静音并把绘制边长压到短边 ≤720；实在解不动就画一张兜底画面并说明，不黑屏、不卡住推进。
旧写法 `@video 名 fps=` 一个字节没坏，老作品打开还是原样。

**二、作品能发给别人，也能接别人的。**
安卓壳之前只会开自己包里的东西。现在作品可以直接分享出去（微信、QQ、文件管理器都认），
别人发来的 `.gal` 点一下就能打开——不用先开 App 再找"导入"。

**三、平板横屏排成三栏。**
横屏大屏以前是把手机那套放大：立绘撑满、选项拉成一条横贯全屏的带子。
现在人物在右、台词和选项在左，各自有边界，1280×800 与 1024×600 都不重叠不出界。

**四、手机上不再「满屏都是框」。**
上一版基本是照着桌面端缩，手机上一眼看过去：台词行挤出屏幕右边、新手大卡片盖住预览、
横屏预览框撑满整屏、首页底部一个能点的地方都没有。这一版按真机截图逐条修——
台词行拆两行（下拉和删除在第一行、台词框独占第二行）；首页加底部四格导航
（作品 / 新建 / 导入 / 设置），横屏时转成左侧竖条；新手卡不再首次自动弹，
要引导走「帮助 → 新手引导」；横屏预览框限高 168px；设置抽屉之前被自己的遮罩盖住、
里面每一项都点不动，现在能点；设置里多了一项「预览比例」（16:9 / 20:9 / 4:3），
只改那块预览框的形状，不动导出结果。

**修掉的真问题：**
- **设置里每一项都点不动**：抽屉和遮罩都没设层级，点击落在遮罩上，只有"点外面关闭"能用。
- **背景名在、图片不在时，预览框说"选背景后这里显示画面预览"**：明明已经选了，缺的是文件。
  现在明说「背景「xxx」找不到文件」，并提示名字对不上或图还没导入——不然人只会反复点那个下拉框。
- **首页中间那块纯黑**：只有一个作品时，卡片下面到动作区之间空着小半屏。
  现在唯一的那张卡自己长高吃掉它，横屏矮屏单独回退成定高，不会穿到导航底下。
- 桌面端换背景时 CG 不退场，两张图叠在一起。
- 转屏后视频进度错乱：时间轴没跟着重置。
- 坏备份导入会先报"已导入"、再把你清空——现在明确报错，不吞。
- 另四处点了没反应、也不报错的静默失败。

- **体积提示真的能到你眼前**：40 MB / 80 MB 的提示以前被接口吞掉了，作者根本看不见，现在看得到。
- **从别的 App 分享进来**：相册里选视频 / 图片分享到 MYONL，先进收件箱，回到编辑器再搬进素材库。

**五、首页少了一课。**
首页原来摆着「三步上手」，编辑器菜单里本来就有「帮助 → 新手引导」，同一套教程说两遍。
删掉了，首页回到只有作品和三个动作。空列表新人的引导走菜单，那里一步不少。

**六、作品能长更大：素材不再全塞进一个 HTML。**
单文件内联这条路，素材到几十 MB 就打不开了。现在分三条：
电脑端 `build_web` 出一个目录（`index.html` + `pack.json` + `assets/`），`pack_apk.py --web-dir`
把它打进 APK；手机端素材超过 30 MB 时自动改走外链，每个素材作为独立条目进包，
`assets/game.html` 只剩剧本几 KB。包的结构是 `assets/` + `assets/assets/` 两层——
`game.html` 自己就躺在 `assets/` 里，它写 `src="assets/bg.png"` 时相对的是自己那一层。
实测标准示例（10 图 6 音频）：输入 21 个文件 → 6,988,225 字节，v2 验签通过，
包内 `game.html` 只有 2,148 字节。

**七、手机端导入 WAV 会转成 webm/opus。**
原来音频一律原样存，理由是「mp3/ogg 已经压过，再转只掉质量不掉体积」。这对 mp3/ogg 成立，
对 WAV 不成立——WAV 是没压缩的 PCM，一分钟 CD 音质约 10 MB，一段台词几百 KB，
全语音作品光语音就上百 MB，24 MB 单文件上限两分钟就顶到。
现在 WAV 走 `MediaRecorder` 转 webm/opus，同样语音小一个数量级。三条护栏：
环境不支持就回退原样存、解码失败也回退并明说、超过 90 秒不硬转（先在手机里剪短）。
**这条路径没有自动化测试**（浏览器 API，node 跑不了），真机「转完是不是真小了、声音对不对」没实测。

**八、导出条先告诉你体积。**
导出面板上多一行：当前作品多少 MB、超 30 MB 建议走 APK。以前是打包那一刻才撞墙，
现在写的时候就看得见。

验收：全量 `1401 passed, 3 skipped`（退出码 0，本地实测 170–175s）；
APK `2,213,701 字节`（较 v1.2.0 增加 9,304 字节 / +0.42%）；安卓壳首次编译通过、签名校验通过。

已知上限：
- 手机端打 APK 时素材不压缩（ZIP 里是 stored），JPG/PNG/OGG 本来就压过，但包里会比素材略大。
- 打 300 MB 级的包，内存峰值约素材两倍，中低端手机可能顶不住；超过 300 MB 会提示分章。
- 「塞进 300 MB 素材后 apk 到底能不能装」**没实测**——本机没有安卓设备，也造不出那么大的样例。

## 2026-11-19 · v1.2.0 · 装上有东西可玩，点按钮真有反应

**这一版三件事：一个装了很久没人发现的哑弹，一个白占体积的示例，一处「编辑器认、引擎不认」的格式。**

**一、APK 里所有「确认 / 取消」弹窗都是哑的。**
安卓外壳从一开始就少装了一个组件，浏览器里那种确认框在包里根本不弹 ——
不弹、不报错、直接当作你点了「取消」。最要命的一处是导入备份：
点「导入」会先问「会覆盖本机进度，确定吗」，那一问从来没出现过，
所以导入永远是静默失败。现在确认框真的会弹出来，确定和取消都真的算数；
页面加载不出来也会明确告诉你，不再是黑屏。

**二、装上打开只有空书架，其实包里带了示例。**
每次构建都往包里塞了一个约 547 KB 的示例游戏，注释写着「装上就能直接玩一关」，
但首页从来没有这个按钮 —— 那 547 KB 一直白占着。现在首页「开始新的」里多一项
「试玩示例」，包里带了才显示，点进去就能玩。

**三、编辑器能收 webp / jpeg，引擎不认。**
导入图片时这四种格式都收，可是运行和打包只找 .png / .jpg。
你拖一张 webp 进去，编辑器里看得见、能摆位置、能预览，
等到打包或运行才报「缺素材」。现在四种都认，大图也会一起压小。

- **竖屏的选项变成了一整块底板**：以前「谁在说 / 说什么 / 能选什么」是三块分开漂在角色
  身上的东西，读起来要来回找；现在底部一张板，名字、问话、选项从上到下一列排好。
  横屏没动，人物在右、选项在左本来就是横屏的标准摆法。
- 长游戏不会越玩越占越多：解出来的图约 1 秒扫一次，超过 160 MB 就从最久没画到的开始放掉，
  当前画面在用的绝不动。低端机上玩到后半段被系统杀掉的情况会少很多。
- 存档写盘改成先写临时文件再替换，写到一半断电/杀进程不会留下一个半截的档；
  主档坏了会自动退到上一次的备份。
- 平板上横屏立绘不再撑满整屏，选项不再拉成一条横贯全屏的带子；平板竖屏的选项也收了宽。

## 2026-11-18 · v1.1.1 · 存档真的存得下来，老手机也点得开

**这一版只说一件事：v1.1.0 里两个「看着正常、实际坏事」的地方修掉了。**

**一、存档导出是假成功。**
v1.1.0 的存到手机上，点了会弹「已导出到下载目录」—— 但包在安卓里根本没有那个目录，
文件一个字节都没写出来。换手机的时候你会以为备份过了，恢复出来才发现全空。
现在它真的调起系统的「保存到」，你选位置，文件就落在那儿；拦下来的时候会明说被拦了，
不再报假成功。

**二、包不大，但一进去还是白屏。**
打开时会把所有图**一次性同时解压**。图的总量前一版已经管住了，可「同时解」这一下
的瞬时占用是稳态的好几倍 —— 内存小一点的手机点进去就是白屏。现在改成一批一批解，
封面排最前面，先出画面再慢慢铺。

- 顺带：素材很多时打包器会把长边降下来（1600 → 1280 → 1024），降到手机扛得住为止。
  真降到过的话，打包结束会告诉你降到了哪一档，不闷着。
- 顺带：手机竖着拿和横着拿，能自动挑`_p` 竖版变体；没做竖版图就回退主图，不会空。

## 2026-11-18 · v1.0.1 · 素材投递区 + 音频进成品 + 从别的 App 分享进来

v1.0.0 只解决「图能进来」，进来之后还得会选文件、会放音乐、会从别处弄素材。
这版把素材入口做完整：

- **投递区**：素材页顶上是一个虚线框，写着「把文件放进来」。手机上点一下弹文件选择，
  桌面上直接把文件拖进去（拖进来时框会亮）。收什么、压多大、多大算超，全写在框里 ——
  不用去猜规则。
- **音频进成品**：mp3 / ogg / m4a 原样存，导出时进 `pack.audio`，播放器的 BGM / 音效 /
  语音三条线本来就读它，接上就能响。
- **守住边界**：单个 24 MB、一次 20 个。超了明确说超了，不静默丢。
  txt / 视频这类成品里用不上的，直接拒收。

  分享是安卓上那条人人都有的路。
- 顺带修：多选里混进一个不能收的文件，进度条会永远卡在「导入中」。

## 2026-11-18 · v1.0.0 · 手机上终于能出带画面的作品

在这之前，手机上做出来的东西**永远是「纯文字 + 蓝渐变底」**：素材页是空的，
导出时素材写死成空对象。等于能跑，但没有画面。

- **素材放在 IndexedDB**，不塞 localStorage。后者总共 5 MB 出头，手机拍的一张图转
  base64 就三四兆，两张就把作品库挤坏。名字索引另存一份，好让接口同步答得上来。
- **选进来就压**：最长边 1280、jpg 0.82。手机原图直接塞进作品，导出的 HTML 会变成
  几十兆，发给谁都打不开。
- **素材页给了真入口**：从相册选图 → 导入进度 → 列表立刻刷出来。
- **缩略图补齐**：图片走浏览器自己的取图通道，绕不过请求劫持，不补就是一排空框。
- **导出带上素材**：成品里就是真画面，导完会提示「带了 N 张图，约 X MB」。
- 顺带修：素材面板层级只有 80，被场景详情页盖住，手机上点「素材」看起来像没反应。

验收（真 Chromium + 本地 HTTP 模拟 APK 环境）：9/9，含「缩略图真的画出像素」
和「成品里 `@bg` 指向的图确实在包里」。
