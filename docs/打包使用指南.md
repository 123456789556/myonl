# 打包使用指南
> 版本：v1.0　日期：2026-10-26　状态：✅ 已定稿

把做好的 Galgame 打包成「双击即玩」的独立应用：作者打包一次，玩家不需要安装 Python、不需要配置任何环境。

## 0. 两种打包方式

| 方式 | 适合 | 需要 Python？ | 耗时 | 产物 |
|---|---|---|---|---|
| 发行版编辑器「📦 打包发布」 | 用 rc6+ 发行包的作者 | **不需要** | 约 1 秒 | ~23 MB |
| 源码版 `pack.py` | 改引擎 / 自定义 exe 图标 | 需要 | 1~2 分钟 | ~23 MB |

发行版编辑器内置一份预构建的**玩家运行库**（`engine/templates/player/MYONLPlayer.exe + _internal`），
打包 = 复制运行库 + 游戏资源，不调用 PyInstaller，所以没有 Python 也能一键出包。
源码构建 `editor.exe` 前先跑一次 `py -3 tools/build_player_template.py`（`build_editor.bat` 会自动补）。

## 1. 源码版：三步打包

### 第一步：准备环境（只需一次）

1. 安装 Python 3.9 或更高版本（发行包用 3.13 冻结；安装时勾选「Add Python to PATH」）
2. 在引擎目录打开命令行，安装依赖与打包工具：

```
pip install -r requirements.txt
pip install pyinstaller
```

### 第二步：整理游戏目录

一个可打包的游戏目录至少包含 `script.gal`，推荐结构：

```
我的游戏/
├─ script.gal          剧本入口（必须）
├─ images/             背景、立绘（png）
├─ audio/              音乐、音效、配音（ogg/mp3/wav）
├─ fonts/              中文字体（强烈建议放一个 simhei.ttf 或 NotoSansCJK.ttc）
└─ plugins/            插件（*.py，可选）
```

> 字体为什么重要：打包后玩家电脑上不一定有你的中文字体。把字体放进 `fonts/`，引擎会**优先使用游戏自带字体**，中文在任何电脑上都不会变成方块。

### 第三步：执行打包

**方式 A：双击 `build.bat`**，按提示拖入游戏目录，或直接把游戏目录拖到 `build.bat` 上。

**方式 B：命令行**

```
python pack.py 我的游戏
python pack.py 我的游戏 --name 示例游戏
```

- 第一个参数：游戏目录
- `--name`：游戏名（决定 exe 文件名与产物目录名；省略时用目录名）

打包完成后得到：

```
dist/示例游戏/
├─ 示例游戏.exe
├─ _internal/          运行时依赖（不要删、不要单独移动 exe）
├─ script.gal
├─ images/  audio/  fonts/  plugins/
└─ saves/              玩家第一次存档后自动生成
```

---

## 2. 怎么发给玩家

把整个 `dist/示例游戏/` 文件夹压缩成 zip 发给玩家即可。

**玩家侧操作**：

1. 解压到任意位置（建议不要放在 C:\Program Files 这类需要管理员权限的目录）
2. 双击 `示例游戏.exe`
3. 开始游戏；存档自动写在 exe 旁边的 `saves/`

玩家电脑**不需要 Python、不需要显卡驱动以外的任何配置**。

## 3. 资源与插件（可见、可替换）

| 目录 | 放什么 | 玩家/作者能否替换 |
|---|---|---|
| `script.gal` | 剧本 | 可以（替换后重开游戏生效） |
| `images/` | 背景、立绘 | 可以（同名覆盖） |
| `audio/` | 音乐、音效、配音 | 可以（同名覆盖） |
| `fonts/` | 中文字体 | 可以（放任意 `.ttf/.ttc/.otf`，引擎优先使用） |
| `plugins/` | 插件脚本 | 可以（放入 `*.py` 后重开游戏生效） |
| `saves/` | 玩家存档 | 删除即「清空存档」，备份即「转移进度」 |

资源全部**原样复制**进产物，没有加密、没有中间格式，方便更新与二次创作。

## 4. 常见问题

**Q1：杀毒软件提示风险 / 拦截 exe？**
PyInstaller 目录模式（onedir）比单文件模式误报少很多，但个别杀软仍可能拦截。把产物目录加入杀软信任区即可；分发时建议附一句说明。

**Q2：游戏里中文显示成方块？**
把中文字体放进游戏目录的 `fonts/`（如 `simhei.ttf`）再重新打包。引擎会优先加载 `fonts/` 里的字体。

**Q3：双击 exe 提示「找不到剧本文件」？**
exe 必须与 `script.gal`、`images/`、`audio/` 等放在同一个目录，不要把 exe 单独拖出来。

**Q4：存档在哪里？换电脑怎么带走？**
存档在 exe 旁的 `saves/`（`slot_1.json` ~ `slot_10.json`、`slot_quick.json`）。复制整个 `saves/` 文件夹即可转移进度。

**Q5：重新打包会不会覆盖玩家存档？**
会。`pack.py` 每次都会重建 `dist/<游戏名>/`，因此发布新版本前请先备份该目录下的 `saves/`，打包完成后再复制回去，避免玩家进度丢失。

**Q6：打包很慢 / 产物很大？**
源码版首次打包约 1~2 分钟，产物约 23 MB（Python 运行时 + pygame）；发行版编辑器用内置玩家模板，约 1 秒完成。这是 onedir 的正常体积，换来的是稳定与资源可替换。

**Q7：能打包成单个 exe 吗？**
当前版本固定使用 onedir（资源外置、存档可见、杀软误报少）。不提供 onefile 模式。

**Q8：发行版提示「缺少玩家模板」？**
说明这个编辑器包不完整（`engine/templates/player` 缺失）。重新下载完整发行包；源码版可跑 `py -3 tools/build_player_template.py` 重新生成。

## 5. 示例

仓库自带 `示例游戏/`，包含剧本、两类背景、两个立绘、一个自动切换夜景的插件 `plugins/night.py` 和中文字体，可用于验证打包链路：

```
python pack.py 示例游戏 --name 示例游戏
```

产物在 `dist/示例游戏/`，双击 `示例游戏.exe` 即可游玩；选择第一个选项后，插件 `@plug:night` 会把教室切换为夜晚背景。
