# MYONL 产品说明书（概念说明书）

> 版本：v2.0　日期：2026-11-02　配套：`engine_spec.md`（技术规格）｜`开发者使用指南.md`（上手教程）
> 状态：✅ 已定稿（2026-11-02 现状，992 项测试通过 + 1 skipped）
> 一句话定位：**完全离线、开源的视觉小说（Galgame）创作与播放引擎——不会编程的人也能做出自己的文字冒险游戏。**

---

## 一、这是什么

MYONL 是一套"**写故事 → 变成游戏**"的工具。创作者用一套极简的文字指令写剧本，引擎负责把剧本翻译、执行、画成画面、存成存档，最终打包成一个玩家双击就能玩的独立游戏。

整个产品由四部分组成：

| 部分 | 干什么 | 使用者 |
|---|---|---|
| **编辑器** | 写剧本、看画面、试玩、打包 | 创作者 |
| **引擎核心** | 解析剧本、执行剧情、渲染画面、存档读档 | 引擎自己 |
| **游戏运行时** | 玩家看到的标题、对话、菜单、设置 | 玩家 |
| **打包发布** | 把游戏做成独立 exe | 创作者 |

**产品铁律**：
- **完全离线**：引擎与编辑器零联网依赖，断网可用
- **本地读写，像离线游戏一样**：剧本/素材/存档/插件全在本地
- **MIT 开源、不盈利**：代码公开可复用
- **Windows 唯一目标平台**（自 v1.0 起放弃 Android/iOS/Web/Linux/macOS）
- **只做视觉小说**：不碰物理、3D、多平台等通用引擎方向

## 二、现在能做什么（能力总览）

截至 2026-11-02（992 项测试通过），MYONL 已经能完整做出一部可玩、可存档、可打包的视觉小说游戏：

**对玩家（玩的人）**
- 开始游戏 / 继续上次进度 / 读取任意存档
- 对话打字机逐字显示，点按推进，长段落自动分页
- 剧情选项分支（键盘选择）
- 随时存档读档（10 个存档位 + 快速存档，带缩略图和章节卡片）
- 回看历史对话
- 设置打字速度、音乐音量、音效音量、配音开关、语言
- 隐藏全部 UI 截图模式、全屏切换、自动播放、快进
- CG 画廊鉴赏、立绘鉴赏

**对创作者（写的人）**
- 用 24 条中文指令写剧本（纯文本，任何编辑器可改）
- 内置 Web 编辑器：左边写剧本、右边实时预览画面
- 语法错误定位、指令自动补全、素材拖拽导入、拖拽式生成指令
- 文件树管理多章节剧本、跨文件跳转、场景时间线
- 一键试玩、一键打包成独立游戏
- **UI 设计面板**：可视化调整圆角/位置/大小（P51 新增）

**对开发者（扩展的人）**
- 插件系统：不碰引擎内核给引擎加新指令
- AI 控制原语：所有操作 JSON 进出，任何 AI 能驱动引擎

## 三、剧本怎么写（核心概念）

剧本是一个 `.gal` 文本文件，每行一条指令，全部是中文直写。**24 条指令就是全部语法**：

| 指令 | 作用 | 例子 |
|---|---|---|
| `@character 名字 颜色` | 登记角色，定名字颜色 | `@character 林晚 #ffc478` |
| `@[名字] 台词` | 让角色说一句话（不需事先登记） | `@[林晚] 你来了。` |
| `@ 台词` | 旁白（不带名字） | `@ 雨停了。` |
| `@[[名字]] 台词` / `@[[整段文字]]` | 整屏独白（NVL） | `@[[林晚]] 那年夏天……` |
| `@bg 图片名` | 换背景图 | `@bg bg_海边` |
| `@music 音乐名` | 播放背景音乐 | `@music bgm_night` |
| `@sfx 音效名` | 播放一次音效 | `@sfx 脚步声` |
| `@voice 音频名` | 给上一句台词配语音 | `@voice 林晚_001` |
| `@video 视频名` | 播放帧序列视频背景 | `@video rain fps=24` |
| `@show 角色 表情` | 显示立绘（可加位置/缩放/动画） | `@show 林晚 微笑 pos=中` |
| `@hide 角色` | 隐藏立绘 | `@hide 林晚` |
| `@anim 角色 参数=起始~结束 秒数` | 立绘补间动画（移动/透明/缩放） | `@anim 林晚 x=-100~0 1.5` |
| `@fg 图片名` | 显示全屏前景图（如雨天玻璃） | `@fg 雨滴` |
| `@choice:` | 弹出选项，玩家选择后跳转 | `@choice:` 下面缩进列选项 |
| `@label 标签名` | 给位置贴名字（章节标记） | `@label start` |
| `@jump 标签名` | 跳到那个位置 | `@jump end` |
| `@if 条件:` | 条件分支（满足才执行缩进块） | `@if 好感 >= 3:` |
| `@set 变量 = 值` | 改变量（好感度等） | `@set 好感 += 1` |
| `@wait 秒数` | 停留几秒 | `@wait 2.0` |
| `@include 文件名` | 引入另一个剧本文件（按章节分文件） | `@include 第一章.gal` |
| `@cg 图片名` | 全屏展示并解锁 CG | `@cg 告白` |
| `@camera pan/zoom/shake/reset` | 镜头运动（平移/缩放/震动） | `@camera shake 1.0` |
| `@transition dissolve/wipe/slide` | 转场效果 | `@transition dissolve 1.0` |
| `@plug:名称 参数` | 调用插件指令 | `@plug:shake 1.0` |
| `@end` | 剧本结束 | `@end` |

**一个完整的例子（当前示例《三幕》的骨架）：**

```
@bg bg_走廊
@label start
@ 放学后的走廊很安静。
@[林晚] 今天也一起回去吗？
@bg bg_天台
@ 天台上风很大，云压得很低。
@bg bg_房间
@ 回到家，我把今天写进了日记里。
@end
```

这就是一部完整的游戏：三张背景、一句角色台词、三句旁白。

**核心设计——存档不怕改剧本**：存档不存"第几行"，而是存"离哪个标签往后数几句"。下次读档重新读剧本、找到标签、往后数几句——所以剧本小改、甚至加新章节，旧存档依然有效。

## 四、游戏运行时：玩家看到的界面和交互

打包后的游戏 = 一个文件夹（exe 入口 + images/audio/fonts/saves + settings.json）。双击 exe 即玩，无需安装任何东西。

### 4.1 标题界面
打开游戏第一屏：游戏标题 + 菜单。菜单项可配置（默认：开始 / 继续 / 画廊 / 设置 / 退出）。

### 4.2 对话界面
- 背景图 + 角色立绘 + 底部对话框（角色名带颜色 + 台词打字机逐字出现）
- **点击 / 空格 / 回车**：推进对话
- 长段落自动分页，右下角有操作提示
- 底部**快捷栏**（可隐藏/显示，可配置按键数量和形状）：SAVE 存档 / LOAD 读档 / LOG 回看 / AUTO 自动播放 / SKIP 快进 / CONFIG 设置

### 4.3 选项分支
剧本 `@choice:` 触发时，屏幕中央出现选项列表：
- **↑ / ↓ 或数字键**：选择
- **回车**：确认
- **Esc**：返回

### 4.4 游戏内菜单
**Esc** 呼出：存档 / 读档 / 回标题 / 设置 / 退出。

### 4.5 存档读档界面
- 10 个存档位 + 快速存档
- 每个存档带**缩略图 + 章节名 + 最后一句台词**（凭画面认档）
- 覆盖保存不二次确认

### 4.6 设置界面
左侧分组：**基础 / 音频 / 语音**。
- 基础：打字速度（慢/中/快）
- 音频：音乐音量、音效音量（滑条，点按拖动调整）
- 语音：配音开关、语音自动推进、语言（中文/English）
- 操作：↑↓ 选择、回车调整、Esc 返回；改动实时生效并写入 settings.json

### 4.7 回看（历史对话）
快捷栏 LOG 或上翻：回看已播对话。

### 4.8 画廊
菜单"画廊"：CG / 立绘 双页签，缩略图网格 + 大图详情，解锁记录存进存档。

### 4.9 隐藏 UI（截图模式）
- **Insert 或 X**：隐藏全部 UI（对话框/快捷栏），只留画面——方便截图
- **P50 顶边 ▼**：切换字幕栏 / 快捷栏显示

### 4.10 快捷键汇总

| 按键 | 作用 |
|---|---|
| 鼠标点击 / 空格 / 回车 | 推进对话 / 确认 |
| ↑ ↓ | 选择选项、设置项 |
| Esc | 返回 / 呼出菜单 |
| F11 | 全屏切换 |
| Insert / X | 隐藏全部 UI（截图模式） |
| F5 | 快速存档（独立 quick 槽，不占 1~10 存档位） |
| 数字 1~9 / 0 | 存档页直达 1~9 / 第 10 格 |
| SKIP / Ctrl | 快进（默认开启，仅已读内容可跳过未读） |
| AUTO | 自动播放 |
| 顶边 ▼ | 切换字幕栏/快捷栏 |

## 五、UI 设计与配置（P51 现状）

### 5.1 UI 风格
- **默认偏圆矩形**（圆角 radius=10），玩家可改成圆角或直角（radius=0）
- **像素化渲染**：Python 程序化绘制 + NEAREST 放大，全 UI 圆角面板统一出口（改一处全局生效）
- 对话框、快捷栏、选项、设置、标题各界面都有独立可调几何

### 5.2 三层配置隔离（引擎默认 ← 项目 ← 玩家）

| 层 | 文件 | 谁改 | 作用 |
|---|---|---|---|
| 引擎默认 | `engine/config.py` | 引擎代码 | 所有项目共享的兜底值 |
| 项目覆盖 | `games\你的游戏\config.json` | 创作者 | 每个游戏独立的设计（圆角/位置/大小/快捷栏/标题菜单） |
| 玩家覆盖 | `settings.json` | 玩家 | 玩家自己的 UI 几何偏好（radius/offset/panel_width 等） |

- 不同游戏项目的默认配置**互相独立**
- 玩家 `ui_geometry` 键：radius（圆角）/ offset_x / offset_y / panel_width / height
- 未知配置键自动忽略，不影响启动

### 5.3 编辑器 UI 设计面板（P51 新增，2026-11-02 增配色）
编辑器里有专门的 **UI 设计区**，按分组调：
- 对话框 / 名字框 / 选项按钮 / 快捷栏 / 游戏内菜单 / 设置页：圆角、位置、尺寸、间距
- **配色**：主色 / 主色暗面 / 强调色 / 面板底 / 次级面板 / 正文 / 次级文字 / 边框 / 危险色 / 成功色，10 个语义主题色用取色器直接改
- 全局：像素化开关 / 像素块大小 / 圆角上限 / 画布尺寸 / 正文字号 / 正文行距
- 实时预览（改动 250ms 防抖刷新右侧画面）
- 保存写回项目 config.json（只改面板列出的键，其余原样保留）；「恢复引擎默认」清空配色覆盖并重置几何

## 六、编辑器：创作工作台

**怎么打开**：运行编辑器（`python -m engine.editor_app` 或打包后的编辑器 exe）。

### 主界面（VS Code / Trae 风格）
- 顶部菜单：文件 / 编辑 / 视图 / 运行 / 帮助
- 左侧活动栏：工程文件 / 素材库 / 设置 / UI 设计
- 中间编辑区：写 `.gal` 剧本源码
- 底部状态栏：语法检查结果 / 行号 / 文件类型

### 核心功能
| 功能 | 干什么 |
|---|---|
| 实时预览 | 左边每改一行，右边画面半秒内刷新 |
| 语法检查 | 错误标红 + 自动跳转到出错行 |
| 自动补全 | 敲 `@` 自动提示指令名、角色名、素材名 |
| 素材库 | 拖图片/音频进素材栏自动归档；拖素材到代码区生成指令行 |
| 缺素材提示 | 底部状态条"第 N 行缺 images/xxx.png"，点击跳转 |
| 文件树 | 多章节剧本管理，跨文件 @label 大纲 + @jump 映射 |
| 场景时间线 | 背景/立绘/音频/选项四泳道，点击节点跳源码行 |
| 一键试玩 | 弹出窗口直接玩当前剧本 |
| 一键打包 | 填游戏名/图标/版本 → 生成可分发游戏包 |
| 新建游戏 | 生成极简空包（一句可改可删的旁白，不预置素材）；要成品观感可复制 `games/标准示例` |
| UI 设计 | 可视化调整圆角/位置/大小（见 5.3） |

## 七、打包与发布

**怎么打包**：`python pack.py "games\你的游戏" --bump patch`（或编辑器菜单"打包发布"）。

打包产物 = 一个文件夹（exe 入口 + 游戏资源），玩家拿到后**双击即玩，零配置**：
```
你的游戏/
├── 游戏.exe        ← 双击入口
├── images/         ← 图片素材
├── audio/          ← 音频素材
├── fonts/          ← 字体
├── saves/          ← 存档（运行时生成）
└── settings.json   ← 玩家设置（运行时生成）
```

打包纪律：必须串行执行（并行会撞锁）；看 stdout"打包完成"判断成功。

## 八、桌宠 Mooki（引擎配套独立工具）

Mooki 是 MYONL 的桌面宠物，**与引擎配套的独立工具，不进游戏包**：
- **默认关闭**；在编辑器「设置 → 桌宠」或「视图 → 桌宠（实验）」打开
- 打开后出现在**屏幕右上角**，玩家可以**拖动**到任意位置
- 左键拖拽，松手自动贴边；位置与大小记在 `~/.mooki.json`
- 右键菜单：打开引擎 / 退出
- 滚轮切换表情、双击冒爱心、`=` / `-` 缩放、Esc 退出
- 独立 Win32 真透明置顶窗口（240×280）；发行版与源码版是同一只 Mooki

## 九、插件系统（给引擎加新能力）

插件 = 给引擎"加新指令"。视觉小说会遇到引擎 24 条指令没有的能力（成就系统、自定义演出），插件让开发者**不碰引擎内核**就能扩展：
- **触发**：剧本里写 `@plug:名称 参数`，引擎运行时查插件表执行
- **文件**：`plugins/xxx.py` 放进去就自动加载，零配置
- **接口**：`register_command("名称", handler)`，handler 收到 (GameState, 参数) 返回事件
- **安全边界**：插件是 Python 代码（全权限），文档明示"只装可信插件"

## 十、当前边界（明确不做 / 未实现）

**明确不做**：
- 通用游戏引擎方向（物理/3D/多平台）
- 引擎内置 AI/大模型（只留控制原语，让外部 AI 接入）
- 商业化、收费、云服务
- 画布拖拽式可视化编辑器

**当前未实现**（规划中）：
- CG 语音回想（CG↔音频绑定）
- 卡片跨文件可编辑
- 撤销栈
