# P60 变更说明：手机上少点手打，少点滑动

P59 之后手机上的三处硬伤：顶部工具条还是文字按钮要横滑、问题/输出面板一打开就吃掉半屏、写剧本要手打 `@` 和缩进。这一轮全补掉。

## 1. 工具条 / 菜单栏收成图标

- `.editor-toolbar` 在窄屏隐藏 `.tb-txt`（文字标签），只留图标：6 个按钮宽 31–35px，一行 390 放得下，不再横滑找按钮。
- `.menubar .mb-acts`（场景 / 角色 / 素材 / 设置四个显式入口）在窄屏隐藏——这些在菜单和 📁 抽屉里都有，重复占位。
- 搜索框收成 34px 圆图标，**点一下才展开**（实测 34 → 131），失焦或点外面自动收回；`Ctrl+Shift+F` 快捷键仍在。

## 2. 底部 Dock 面板收高

`.dock` 原固定 180px，窄屏改成 `38dvh`（390×844 上实测 321px）。打开问题/输出/运行日志时编辑区还剩一半，不再被压没。

## 3. 手机键盘快捷条

写剧本最疼的是 `@`、`@choice:`、缩进这些高频输入。加一条贴着状态栏的横滑快捷键条（`.m-keybar`，高 49px）：

`@` · `@choice:` · `@if` · `@set` · `@label` · `@show` · `→` · `缩进` · `换行` · `撤销`

- 只在窄屏 + 剧本输入框聚焦时出现；出现时浮动按钮（📁🗂👁▶）自动让位。
- 每个按钮 `pointerdown` 都 `preventDefault`，点快捷键时输入框**不失焦**，插入位置不丢（实测插入后 `activeElement` 仍是 `#source`）。
- 插入用 `setRangeText` 并补发 `input`/`keyup` 事件，语法检查和预览照常刷新。
- `@choice:` 会连缩进一起写（`@choice:\n    `），省掉"换行 + 缩进"两步。
- `缩进` 按当前行行首插 4 空格；`撤销` 走浏览器原生 `execCommand("undo")`，撤销栈不破。
- 用 `visualViewport` 的 `height + offsetTop` 算键盘占位：iOS 不缩 viewport 时把快捷条顶到键盘上方，安卓靠 viewport 自然缩。

## 语音转文字：不做

理由：手机输入法自带的语音键就是现成的；浏览器里再套 Web Speech API，iOS Safari 支持残缺、安卓 Chrome 要联网，跟"离线可跑"的定位冲突。做出来是"能点、不准、还得联网"的负资产。

## 边界

- 快捷条是固定的一组常用指令，没做成"根据当前行上下文推荐下一句"的智能提示。
- 横滑快捷条没有做手势分组（比如长按弹出全部指令列表）。
