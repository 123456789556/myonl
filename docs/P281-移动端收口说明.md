## 1. 蓝竖条判定：分栏拖宽把手，保留功能、改成 1px 细线

**判定：不是残留装饰。** 它是横屏 / 平板分栏时拖宽左栏与预览栏的把手：

- 左栏把手 `#mRailGrip`（class `.m-rail-grip`）
- 预览把手 `#mPrevGrip`（`.m-prev-grip`）
- 规则位置：`editor/editor.css:3041-3048`

**改前**（旧包对照实测，1024×768）：

- 可见物是 5px×48px、`rgba(79,140,255,.35)`、圆角 3px 的蓝胶囊；命中轨迹槽 22px 居中。
- 把手槽 x=569、右缘 591；舞台盒右缘 593——轨迹槽已探进图缘 2px，5px 胶囊居中压在舞台图上（图缘内约 5px 量级）。

**改后**（本轮实测，1024×768）：

- 命中区 22px 不动；常态可见物 **1px×44px / 透明度 .28** 细线；拖动中 `.on` 态 **2px×56px / .8**。
- 细线离舞台图缘 **+8px**：舞台右缘 593，预览把手槽 x=582、`::after` left=19px，细线 x=601，601 − 593 = 8px。
- 预览把手整体偏移 **+13px** 对齐舞台盒右缘：`editor.css:3043` `calc(var(--m-rail,232px) + var(--m-prev,34%) + 13px)`。

处理方式 = 拖拽功能保留，只改可见物粗细、透明度和离图边距离。

## 7. 参数表单：六类本就有，这轮抬一级

六类表单本来就在 `editor/editor_perf.js:23-24`（`LABEL` / `OPS`）：`@voice` 配音、`@cg` CG、`@fg` 前景、`@camera` 镜头、`@transition` 转场、`@anim` 补间。

这轮把演出表单从折叠里抬到一级「演出」一行；素材 / 角色 / 选项 / 跳转 / 变量与条件收进新文件 `editor/editor_setup.js` 的「场景设置」折叠（48 行；`summary()` `:21`、`wrap()` `:30`、`watch()` `:41`）。

实测写回两行（node 调 `parseText` 实跑）：

```text
@camera pan 左 0.6
  → {op:"camera", kind:"pan", args:["左", 0.6], line:1}

@anim 小满 x=-100~0 0.6
  → {op:"anim", char:"小满", param:"x", from:-100, to:0, secs:0.6, ease:"linear", line:1}
```

**镜头为什么必须带 pan 子命令**：`@camera` 第一参只认 `pan / zoom / shake / reset`（`engine/parser.js:372-383`）；裸写方向词会被拒：

```text
@camera 左 0.6
  → 拒收：@camera 子命令 "左" 不支持（pan/zoom/shake/reset）
```
