# P65：手机端分层（纯文字 tab + 全屏 + 浅深两套）

## 一、真机暴露的问题（不是"调不好"，是设计错）

真机（vivo V2323A / Android 16 / 1080×2400）打开编辑器，屏幕上依次是：

```
浏览器搜索栏        ~130px（不是我们的）
菜单栏 文件 编辑 视图 运行 帮助
活动栏 📁 🗂️ ⚙️ ?   ← 一排图标
编辑器工具条         ← 一排图标
标签页 script.gal × +
面包屑 MYONL引擎 > games/教程示例/script.gal > start
格式条 B I 颜色… 字号…
--------------------------------
才轮到剧本正文
```

顶部吃掉约 1/3 屏幕。这是把桌面三列 IDE 直接塞进 390 宽的必然后果，不是某一处 padding 没调好。

## 二、改法：默认只留一行，要用的才展开

手机端（`max-width: 860px`）现在的结构：

- **顶栏一行**：`文件` + `⛶`（全屏）+ `⋯`（展开工具条）
  - 编辑/视图/运行/帮助 隐藏（功能都在 `⋯` 工具条和底部 tab 里）
  - 活动栏、搜索框、品牌字、面包屑 隐藏（手机上只占高度、不给信息）
- **正文占满**
- **底部一条 tab（纯文字）**：剧本 / 素材 / 外观 / 预览 / 导出
  - 不放 emoji：✎🖼🎨▶⬇ 风格不统一，看着像随手拼的
  - 选中态 = 蓝色文字 + 顶部 2px 蓝线
- **状态栏**贴最底：已保存 · 就绪 · 第 N 行 · 语法检查 · 指令数

原来右侧 4 个浮圆按钮（📁🗂👁▶）退役：和 tab 重复，还压正文最后几行。

### 各 tab 干什么

| tab | 行为 |
|---|---|
| 剧本 | 关掉所有抽屉，回到编辑区 |
| 素材 | 右侧抽屉滑出（`mobile-asset-open`），内含「◉ 拍照」直连相机 |
| 外观 | 打开「界面设计」弹窗（对话框样式/配色/圆角） |
| 预览 | 底部抽屉升起（`mobile-preview-open`） |
| 导出 | 打开「界面设计」弹窗（导出单文件在里面） |

## 三、全屏（"竖屏肯定是要全屏的"）

真机上浏览器自己的工具栏 + 底部工具栏吃掉约 250px，裸 `.html` 永远不是沉浸的。两条路都做了：

1. **页面内全屏按钮**：顶栏 `⛶` → `requestFullscreen()`（用户手势内调用，浏览器允许）
2. **PWA 全屏**：`editor/manifest.webmanifest`（`display: fullscreen`）+ `icon-192.png` / `icon-512.png`
   - 手机浏览器「添加到主屏幕」后，从桌面图标启动 = 没有地址栏、没有工具栏
   - 服务端新增 `/manifest.webmanifest`、`/icon-192.png`、`/icon-512.png` 三条路由

游戏侧（播放器 `web/myonl-player.js`）：点标题页「开始」的那一下顺带 `requestFullscreen()`，
失败就静默跳过（桌面浏览器、被策略禁用的环境都常见）。`resize` / `orientationchange` 已有监听，全屏后会自动重算画布。

## 四、浅色 / 深色两套

编辑器本来就有 `data-theme="light"` 全套变量覆盖（`editor_pro.js` 的 `applyTheme` + localStorage `gal_editor_theme`），
只是默认深色、手机上看不到切换入口。现在顶栏 `⋯` 展开后即可切换，状态栏也能切。

手机端 tab / 顶栏全部改用 `var(--xxx)`，所以换肤跟着走，不需要第二套 CSS。

## 五、新手引导改成手机版

原来三步文案讲的是「左边是工程文件，中间写剧本，右边实时预览」——手机上根本没有三列，第一句话就对不上。
手机端换成：

1. 「底部五个 tab」——每个 tab 干什么
2. 「写第一行」——每行以 `@` 开头，旁白/台词各什么写法
3. 「看效果 / 发出去」——预览试玩，导出 html 发给别人

引导卡片位置从 `bottom: 56px` 抬到 `bottom: 96px`，不再压住底部 tab。

## 六、诊断口（排查手机定位问题用）

`editor_shell.js` 里加了 `?diag=1`：屏幕左上角显示 `inner / visualViewport / dpr / body 高度 / tab 实际位置`。
手机上出现"元素浮在屏幕中间"这类问题时，靠这行数字判，不靠猜。

## 七、还没做（如实记录）

1. **游戏方向的设置项**（跟随手机 / 锁竖屏 / 锁横屏）：`config.orientation` 还没进 config 与播放器。
   现在游戏是"跟随手机自动重排"（竖横两套布局都已实现并截图验证），但没有用户可选的锁定。
   浏览器里真锁方向只在全屏 + `screen.orientation.lock()` 下有效，需要按上面的全屏路径才成立。
2. **编辑器横屏布局**：手机横过来仍然是竖屏布局（横屏宽度 > 860 会走桌面三列，那更烂）。这一版没有专门设计横屏编辑器。
3. **工程卡片工作台首页**：现在是"进编辑器直接看到剧本"，还没有「工程列表 → 点进去」这一层。
4. 真机本轮未复验：adb 反复 offline，P65 的截图是 390×844 Chromium（`p65-web-dark.png` / `p65-web-light.png`）
   与上一轮真机（`android-p65-2.png`，tab 已贴底）共同确认的。
