# 手机端编游戏：能做什么、不能做什么

装一个 APK，打开就是编辑器。**不需要连电脑，不需要服务器，也不上传。**

> 本文只写手机上这条链路的真实边界。谁和这里说的不一样，以这里为准（README 其次）。
> 最后一次按代码核对：2026-11-19，v1.2.0。

## 能做

| 事情 | 说明 | 存在哪 |
|---|---|---|
| 新建作品 | 起个名直接开写，自带一句可以立刻改的示例台词 | localStorage 作品库 |
| 写剧本 | 手机键盘输入，`.gal` 语法，缩进、`@` 指令照常 | 同上 |
| 放图片 | 从相册选、拖进来、从别的 App「分享」进来都行 | **IndexedDB**（不是 5 MB 的 localStorage） |
| 压图 | 进来就缩到最长边 1280、转 JPEG q0.82，一张约 100~200 KB | 自动 |
| 放音乐 | 音频原样存，进成品当 BGM / 音效 | IndexedDB |
| 视频（真文件） | 相册选、从别的 App 分享进来的真视频原样存（不压、不转码）；单文件 ≤24 MB；播放器同时只解一个视频，切幕 / 切背景立刻释放；内存小的低端机自动降级 | IndexedDB |
| 出成品 | **本机直接把剧本 + 素材拼成一个自包含 `.html`** | `engine/parser.js` + `engine/pack.js` |
| 带走剧本 | 导出 `.gal`（一份文本）/ `.json`（整个作品库，含素材原图） | 系统「保存到」 |
| 试玩示例 | APK 首页「试玩示例」，不建作品也能先看成品长什么样 | 内置示例 |

「出成品」走的是 `engine/parser.js` + `engine/pack.js`，和电脑端 `engine/parser.py` 逐字段一致
（`tools/pack_diff.py` 拿 `games/` 下全部工程对拍）。**手机上打出来的包和电脑上打出来的是同一个东西。**

## 不能做（这些还是电脑的活）

| 事情 | 为什么 |
|---|---|
| `@voice` `@anim` `@fg` `@cg` `@camera` `@transition` `@plug` | 这 7 条手机端解析器没实现，**遇到会明确报错并指出是第几行**，不会静默吞掉。要做配音/立绘动画/前景/CG/镜头/转场/插件，用电脑端打包 |
| `@include` 引入别的文件 | 手机上的作品是**一份文本**，没有第二个文件可引 |
| 打包 APK | 打 APK 要 Android SDK + 签名，走 GitHub Actions，不在手机上做 |
| 跑测试 | `pytest` 是 Python 套件，只在电脑上 |

手机端解析器认这些指令：`@character` `@bg` `@music` `@sfx` `@show` `@hide` `@wait`
`@chapter` `@label` `@jump` `@end` `@set` `@if` `@video`，外加选项块 `@choice:` 和没前缀的台词行。

## 视频在手机上的两种走法

`@video` 有两条通道，写法不同：

- **帧序列**（不写 `file`）：帧图放 `images/videos/名_001.png` 起连续编号，`@video 名 fps=24`。
  播放器只保留最近用过的少量帧，切走立刻释放，避免一长串帧把内存吃满。
- **真视频文件**（写 `file`）：`@video 名 file`，走 `<video>` 解码；可追加 `loop=0|1`、`mute`。
  整段成品同时只活一个 `<video>`，切幕 / 切背景 / 读档 / 退出立刻 pause、清 src、释放元素。

## 成品怎么给别人

导出的 `<名字>.html` 是一个自包含文件：播放器、剧本、素材全在里面。

- 微信 / QQ 发过去，对方点开用浏览器打开就能玩（不用装东西、不用联网）；
- 自己留着，双击也能玩；
- 素材多到 40 MB 以上，导出时会当场提示体积和风险；超过 80 MB 会警告「低端机会明显卡」——
  想瘦就先缩图，不要在手机上硬塞几百 MB 的原图。

## 升级会不会把作品弄丢

不会。作品和素材在应用私有目录里，**签名固定**（`android/keystore/myonl-test.p12`），
覆盖安装是升级而不是换 App，存储不会被清。刻意不换签名就是为了这个——换签名等于逼所有人卸载重装，
卸载会连存档一起删。

保险做法：出成品前导一份 `.json` 作品库备份。那是纯数据，随你拷到哪。

### 备份里带哪些素材

现在的 `.json` 备份分三桶：**assets（图）/ audio（音频）/ movies（真视频）**，外加一份
**kinds 类型索引**；导入时按 movies → kinds → assets 优先级还原，视频回来仍是 video，不会被当图。

**旧备份救不回视频类型**：更早的两桶备份只有 assets + audio，当年视频被混在图桶里、类型没带走。
这种旧文件仍能导入，但里面的视频只能按图片还原——不是新备份的问题，是旧文件当年就丢了类型，
别指望换机后视频还能播。

## 一句话边界

手机上：**写、放图放音乐、出成品、发出去。**
电脑上：**配音/动画/前景/CG/镜头/转场/插件、多文件剧本、打 APK、跑测试。**
