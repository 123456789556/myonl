# ROADMAP

> 版本：v1.1（引擎工具定位）　日期：2026-11-01　替代旧的 P 阶段任务书体系（历史见 archive/）
> **产品定位：MYONL 是引擎工具，不做游戏成品。** 示例游戏（标准模板《晚风与约定》）只作「可改的小样板」，
> 用来证明引擎能跑、给人抄着改，不作为产品交付。

## 北极星（唯一进度指标）

**在干净 Windows（Windows Sandbox / 新建用户，等价陌生人环境）零帮助 30 分钟内做出并打包一个能玩的小 demo → 愿意继续用 / 留言。**

其它数字（tests / coverage / pyright）只是门禁：绿灯即可，不追高、不当进度。
