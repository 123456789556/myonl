## 二、"乱搞"的五种具体形态（出现即打回）

1. **不读 UPDATE 就开工**：不知道上一期做到哪，重复实现已有功能，或把已删的东西搬回来（`games\研修日志`、`作品\副产物\月光漫步` 已移出，见 `发布纪律.md`）。
2. **改接口不报告**：`.gal` 的 22 条 `@指令`、存档键格式（`myonl:v2:save:<指纹>`）、`config.json` 字段，动一处就是改验收基准；发现冲突要写进变更说明"偏差"节，不许自己改任务书。
3. **把产物当源码提交**：`dist\`、`build\`、`saves\`、`screenshots\`、`.pytest_cache\`、`engine\templates\player\_internal\`（实测 20.32 MB 本地产物，`git ls-files` = 0，别手滑 `git add`）。
4. **冻结期加功能**：M1 期间 `engine\` 只收"阻塞陌生人上手"的 P0 修复，功能一律进 BACKLOG。
5. **报"绿"却没跑**：`STATUS.md` 里"1174 passed""覆盖率 80.49%"这类数字是**历史声明**，不是现状。引用前重跑，或写明"未复跑"。

## 三、版权四条红线（比功能重要，破一条就毁项目）

1. **别人的游戏、图、音乐、字体 —— 一张都不进公开仓库。** 「只放一个示例」「仅本地测试」不是理由，推上去就是再分发。真要用，走 `MYONL-publish`。
2. **别人写的代码引入必须带原文许可。** Ren'Py 是 MIT（可参考、可抄模块，但要留 Copyright 与 LICENSE）；pygame-ce 是 LGPL-2.1+（动态链接使用，`NOTICE` 已声明，不许改成静态链接后还沿用同一份 NOTICE）。
3. **改名先检索，不许随手换。** 历史已因撞名改过两次（Selene → Moyul → MYONL）。换名会连带改 `%APPDATA%\Moyul` 存档冻结位、包名、图标与文档 100+ 处——**这不是重命名，是迁移**，必须用户拍板。
4. **AI 生成的素材要留档。** 出图/出视频用的模型、提示词、日期、平台条款要能查；条款禁止商用的，不能进发行包。

### 缺一份"素材来源登记"（当前最大漏洞）

实测：仓库里 **PNG 155 张 / 31.63 MB、JPG 23 张 / 3.28 MB、OGG 24 个 / 1.09 MB**，**没有任何一张登记来源**。现在靠"我记得是自己做的"——接手人接不了这个记忆。建议按下面格式补一张表（放 `docs\素材来源登记.md`）：

```markdown
| 路径 | 类型 | 来源 | 生成/取得日期 | 许可 | 可否商用 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| brand\icon-512.png | 图标 | 自己画（Illustrator） | 2026-10-30 | 自有 | 可 |
| games\教程示例\assets\bg_教室.jpg | 背景 | AI 生成（模型名 / 平台） | 2026-11-14 | 平台条款第 X 条 | 待核 |
| ... | 音乐 | 曲库名 / 作者 / 授权截图 | ... | CC0 / 购买凭证 | 可 |
```

判据：**填不出"来源 + 许可"的资产，一律不得进发行包。**

## 六、交接留痕（写在哪、写什么）

交接不靠口头。在 `docs\STATUS.md` 顶部四行内写清，或在 `docs\CHANGELOG.md` 追加一条：

```
2026-11-18 交接：A → B
HEAD 059171c（设置面板只留一个出口）
实测 1183 passed + 1 skipped（not slow）
未完成：鉴赏页数据链路 / 立绘分层 / 桌面端其余页
未提交改动：112 条（属 A 的在途工作，B 接手前先确认）
```

**"100+ 条未提交"必须在交接时点明归属**——2026-11-18 实测工作区长期挂着大量脏改动（19:47 = 112 条，21:00 = 118 条，仍在涨，另一会话在写），接手人一律当成自己的活去提交，会把别人的半成品一起推上去。

## 七、什么时候必须停下来找用户拍板

- 要删/移任何目录、素材、存档格式
- 要改 `.gal` 指令集、存档键、`config.json` 字段
- 要改名、换图标、换仓库地址
- 要把任何第三方内容放进公开仓库
- 发现文档与磁盘不一致（先改文档并登记，不许"只记不改"）
- 测试红了但不是你改的那部分（先定位归属，别顺手改别人的代码）
