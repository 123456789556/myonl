# 变更说明 P56 · 全面转手机端 + 可迁移导出（Ren'Py / 通用 JSON）

日期：2026-11-16
接 P54（H5 播放器）、P55（安卓壳），这一轮定的是**方向**和**出口**。

## 一、方向：桌面端降为并行出口，手机端是主线

之前的口径是「Windows 视觉小说引擎」，手机是附加能力。现在反过来：

| 位置 | 以前 | 现在 |
|---|---|---|
| 主线 | 双击 exe 的桌面游戏 | 手机竖屏/横屏网页包 + 安卓 APK |
| 桌面 | 唯一出口 | 并行出口（同一份剧本，同一套 IR） |
| 新功能默认 | 先在桌面做 | 先问「手机上怎么表现」 |

改的不是代码路径，是**优先级**。README 第一段、编辑器弹窗文案、导出按钮的位置都跟着改了：
手机版和可迁移包两个按钮都在「界面设计」弹窗底部，不藏在皮肤页签里。

## 二、出口：一个工程，三种去处

```
                     ┌── dist/web/<工程名>/     H5（手机 / itch.io / 静态托管）
剧本 script.gal ──→ IR ─┼── dist/portable/<工程名>/renpy/   Ren'Py 工程
（parser 唯一一份）     └── dist/portable/<工程名>/json/    通用 JSON（谁都能读）
```

### 1. Ren'Py 投影（`engine/portable.py`）

- `character` → `define c1 = Character("林晚", who_color="#ffb3c8")`
- `bg` → `scene bg1`；`show 林晚 微笑` → `show s1`（**中文图名统一换成 `bg1/s1/label_1/c1` 这类 ASCII 短名**，
  原名写在行尾注释里，原因见"边界"）
- `choice` → `menu:` + `jump`；`if` → `if 好感 >= 3:`；`set` → `$ 好感 += 2`；`wait` → `pause 1`；`end` → `return`
- 剧本第一条 `label` 之前的散指令：Ren'Py 不允许顶层散语句，统一收进合成的 `label start`
  （原 `start` 改名 `start_orig`，合成 label 末尾 `jump start_orig`），保证「背景/初始化变量」不丢

### 2. 通用 JSON（`game.json` + `assets/` + README）

`format: "myonl-ir/1"`，字段就是 MYONL 的 IR（op 名一一对应），README 里带完整 op 表。
任何引擎照表实现 op 就能读；也方便做校对、统计、二次转换。

### 3. 编辑器入口

- 按钮「导出 Ren'Py + JSON」→ `POST /api/export-portable`（`engine` 可填 renpy/json/both）；
- 产物落到 `<发行根>/dist/portable/<工程名>/`，每种引擎打一个 zip；
- 下载走 `GET /portable-file/<文件名>.zip`（realpath 前缀校验，`../` 400，非 zip 404，中文名走 RFC 5987）。

## 三、边界（这些是真的没做，别当 bug）

- **中文标识符统一换 ASCII**：Ren'Py 的图像名/label 名走标识符规则，中文在部分工具链上会编不过；
  所以短名换英文、原名进注释（`README.md` 里有完整对照表）。
- **桌面专属指令不投影**：`music/play/stop/video/cg/fg/camera/shake/anim/transition/chapter/plug/voice`
  只记进 `unsupported`，不生成任何假效果——假装支持比不写更坏。
- **对话框皮肤（九宫格贴图）不投影**：Ren'Py 用自己的 textbox 机制，硬塞过去只会互相打脸。
- **Ren'Py 工程没有跑过 Ren'Py**：本机没有 Ren'Py SDK，语法结构是按 Ren'Py 文档写的，
  真机首次打开可能需要修一两处（已知高风险点：`$ 好感 += 2` 这类中文变量名）。
- **变量名保持中文**：Python 3 允许，但 Ren'Py 的 lint 可能更严；作者改英文更稳。
