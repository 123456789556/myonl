# 变更说明 · P54 手机版（竖屏 + 横屏都能跑）

> 一句话：MYONL 多了一个出口——把同一个工程编成**静态网页包**，手机竖屏、横屏都能跑，
> 转屏会自动重排。桌面引擎不变，作者还是照旧写剧本、调 UI。

## 为什么做这件事

Ren'Py 的出口是桌面（Windows/Linux/macOS），它出不了竖屏 H5，也上不了 itch.io 的网页区、
微信/抖音小游戏这些地方。所以「竖屏 + 横屏的手机播放器」不是给 Ren'Py 老用户准备的，
是给**只有手机、只想发个链接让人玩**的作者准备的。

这条路的成本必须低，否则不如不做。所以分工是硬约束：

| 谁 | 干什么 | 不干什么 |
|---|---|---|
| Python（桌面引擎） | **编译器**：解析剧本 → IR → `pack.json` | 不实现第二套播放逻辑 |
| JS（手机播放器） | **播放器**：执行同一套 IR | 不实现剧本语法（语法只有 `engine/parser.py` 一份） |

这样以后要包成微信小游戏 / 抖音小游戏，只是给这个播放器加壳，不用重做内容管线。

## 怎么用

### 命令行（CI / 脚本 / 批量）

```bat
py -3 -m engine.webpack "games\教程示例" -o "dist\web\教程示例"
```

产出（一个可以直接上传的静态目录）：

```
pack.json          剧本 IR + 角色表 + 视觉配置 + 素材清单
index.html         入口（引用下面三个 js）
myonl-core.js      内核：执行 IR、变量插值、比较、存档
myonl-layout.js    布局：竖屏/横屏算尺寸（纯函数，可 node 测）
myonl-player.js    播放器：canvas 画背景/立绘/面板/台词/选项
assets/*.png       只拷**剧本真正引用到**的图（不整目录搬）
```

本地预览不要双击 `index.html`（`file://` 取不到 `pack.json`），起个静态服务：

```bat
cd dist\web\教程示例
py -3 -m http.server 8777 --bind 127.0.0.1
```

然后浏览器开 `http://127.0.0.1:8777/index.html`。

### 编辑器里（作者日常）

「界面设计」弹窗底部新增 **导出手机版** 按钮：

1. 点一下 → 后端把当前工程编译到 `<发行根>/web/<工程名>/`；
2. 同时把该目录挂在 `/web-preview/` 上，返回「打开手机版预览」链接；
3. 缺素材、桌面端有而手机端暂不支持的指令，都会写在按钮旁边（不静默吞掉）。

## 竖屏 / 横屏怎么处理

不是两套页面，是**一套画布跟着窗口比例变**（`web/myonl-layout.js`）：

- 短边固定 1080，长边按真实窗口比例算 → 手机上真正满屏，不留黑边；
- 长宽比只夹 `0.42 ~ 2.2`（比 iPhone 竖屏还窄、比手机横屏还宽的极端情况才夹）；
- **字号按短边算**，所以转屏不会变成蚂蚁字或巨字（冒烟里断言了「横竖屏字号差 ≤ 4」）：
  手机竖屏 42px / 横屏 42px；
- 竖屏面板约 30% 高、横屏约 34% 但面板更窄（最多占宽 82%），文字按新宽度重新折行；
- 转屏时**保住当前台词和打字进度**（`rewrap()` 把已显示字数按比例续上，不重播不跳字）。

## 手机端读的是同一份配置

播放器不自己发明一套视觉，而是读 `pack.json.config`（`dialogue.default` + 主题色）：

- 对话框皮肤走**同一套语义**：`panel_image` 九宫格（`panel_slice` 单值或 `[l,t,r,b]`）
  + `panel_texture` 平铺 + `panel_texture_alpha` 强度 + `panel_alpha` 总透明 + `pad_x/pad_y`；
- 皮肤是半透明 PNG 时，底下先垫一层不透明底板（`rgba(10,12,18,.90)`），否则背景/立绘透上来会看不清字；
- 角色名字颜色来自剧本里的 `@character`（`pack.json.characters`）。

## 支持 / 暂不支持（如实写）

支持：`@character`、`@bg`、`@show`、`@hide`、`@[角色]` 台词、`@ 旁白`、`@choice`、`@jump`、
`@label`、`@set`、`@if`（含 `else`）、`@wait`、`@end`；`{变量}` 插值；`== != > >= < <=` 比较；
自动存档 + 「继续上次」。

暂不支持（编译时列进 `pack.json.unsupported`，播放器控制台会提示，不假装支持）：
`@music`、`@play`、`@stop`（音频）、`@video`、`@cg`、`@fg`、`@camera`、`@shake`、`@anim`。

## 已知限制（没做，不粉饰）

1. **没有声音**：`@music/@play/@stop` 归到 unsupported。手机浏览器还需要用户手势才能出声，
   要做得对得单独一轮。
2. **只有一个自动存档槽**，没有多槽位/手动存档界面。
3. **没有历史回看、快进、跳过已读**——桌面端有，手机端还没搬。
4. **立绘只支持居中/按人数均分**，没有 `@show` 的位移/缩放参数（桌面端那套 `@anim` 也没搬）。
5. **没有进度条/设置面板**，标题页只有「开始」和「继续」。
6. 背景是 **cover 裁切**：竖屏会把 16:9 的图左右裁掉，作者需要自己留安全区（或按竖屏出图）。
7. 微信/抖音小游戏封装**没做**，现在只是通用 H5 静态包。

## 实现位置

- `engine/webpack.py`：编译器（`build_web()` + CLI）
- `web/myonl-core.js`：IR 执行器（VM）
- `web/myonl-layout.js`：布局计算（纯函数）
- `web/myonl-player.js`：canvas 播放器（竖屏/横屏自适应）
- `web/test/vm-smoke.js`、`web/test/layout-smoke.js`：node 冒烟
- `tools/web_shot.py`：真实浏览器验收 + 截图
- `engine/editor.py`：`POST /api/export-web`、`GET /web-preview/...`
- `editor/editor_uidesign.js`：界面设计弹窗里的「导出手机版」按钮
- `tests/test_webpack.py`：11 条守护
