## 三、未完成与下一步

### 1. Windows Sandbox 零帮助自测（唯一门槛，10–30 分钟）

干净 Windows 环境 = 无 Python、无工程、无缓存，等价首次使用者环境；以自动化等价验证为主，人工抽测补充。

- 方案 A（推荐）：Win10/11 专业版自带 Windows Sandbox；首次在「启用或关闭 Windows 功能」勾选并重启。
- 家庭版：方案 B 新建标准本地用户 → 方案 C U 盘到另一台电脑 → 方案 D 云电脑/远程桌面。

**清单**（把 rc3 zip 解压到纯英文路径，逐项记录）：

| # | 动作 | 通过标准 |
|---|---|---|
| 1 | 解压 zip | 无报错，`editor/editor.exe` 存在 |
| 2 | 双击 `tools/win_env_check.bat` | 记录系统 / Python / WebView2 / 路径 |
| 3 | 双击 editor.exe | 10 秒内出界面，不提示缺 DLL/Python |
| 4 | 打开「教程示例」 | 文件树 / 代码 / 预览正常 |
