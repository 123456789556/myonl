# 快速上手（3 分钟做出你的第一幕）

> 目标：从零到「改一句台词 → 预览 → 打包成能双击玩的 exe」。
> 不需要懂编程，会改文本文件就行。

## 1. 拿到引擎

### 方式 A：发行包（推荐）

1. 解压 `MYONL引擎-v1.0.0-rc6.zip` 到任意目录（不要放在需要管理员权限的 Program Files 下）
2. 双击 `editor/editor.exe`
3. 编辑器会自动打开 `games/教程示例` 工程；右侧能看到实时预览

> 编辑器依赖系统 WebView2（Win10/11 自带）。打不开窗口时，用方式 B 的浏览器模式。

### 方式 B：源码

```powershell
pip install -r requirements.txt
py -3 -m engine.editor --project games/教程示例
```

浏览器打开终端里打印的 `http://127.0.0.1:8000`。

## 2. 五步做出第一幕

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| 1 | 左侧文件树点开 `script.gal` | 左栏 |
| 2 | 把 `@[林晚] 你还不走？` 改成你自己的台词 | 中间编辑区 |
| 3 | Ctrl+S 保存，右侧自动刷新预览 | 右栏 |
| 4 | 点顶部「▶ 运行」（或 Ctrl+R）→ 弹出真窗口试玩 | 顶部按钮 |
| 5 | 点顶部「📦 打包发布」→ 选工程 → 填游戏名 → 开始打包 | 顶部按钮 |

打包产物在目录的 `dist/<游戏名>/<游戏名>.exe`，双击即玩，可以拷给朋友。发行版内置玩家运行库，**打包不需要安装 Python 或 PyInstaller**，通常 1 秒左右完成。

## 3. 新建自己的工程

- 编辑器里：「＋ 新建游戏」→ 填名字 → 选主题 → 创建
- 命令行：`py -3 -m engine.cli new 我的第一个游戏`

编辑器新建的工程是**极简空包**：只有一句可改可删的旁白 `@ hello world!`，不预置图片/音频。
想要现成观感（背景 + 立绘 + 音效 + 三幕示例），直接复制 `games/教程示例` 再改；命令行新建则是带注释的教学骨架。
工程始终包含：剧本 `script.gal`、配置 `config.json`、素材目录 `images/`、`audio/`、打包档案 `pack_config.json`。

## 4. 写剧本的小技巧

| 想做的事 | 写法 / 操作 |
|---|---|
| 换背景 | `@bg bg_教室`（图片放 `images/`，文件名对应） |
| 显示立绘 | `@show 林晚 微笑`（文件 `images/林晚_微笑.png`） |
| 角色台词 | `@[林晚] 你还不走？`（方括号标角色，不需要先登记） |
| 旁白 | `@ 晚风很轻。` 或单独一行 `@` 后换行写文字 |
| 分支选项 | `@choice:` 下一行缩进写 `> 选项文字 -> 标签名` |
| 改数值/判断 | `@set 好感 += 1` / `@if 好感 >= 3:` 下缩进写台词 |
| 改完立刻看效果 | 启动时加 `--hot-reload`：改剧本 0.5 秒内从当前场景重播 |

> 写错了不要紧：编辑器会提示第几行什么错，右侧预览也会标红。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 预览出现红字 / 占位色块 | 剧本引用的素材不存在：检查 `images/` 文件名与大小写 |
| 双击 editor.exe 没窗口 | 缺 WebView2：装 Edge WebView2 Runtime（https://developer.microsoft.com/microsoft-edge/webview2/ ），或用方式 B |
| 双击编辑器/游戏提示「已保护你的电脑」 | 未签名程序的 SmartScreen 提示：点「更多信息」→「仍要运行」 |
| 打包慢 / 包大 | 发行版打包约 1 秒（复制内置玩家运行库）；产物约 23MB，删掉不用的素材可再减小 |
| 想换掉示例 | 直接改 `games/教程示例`，或用「＋ 新建游戏」 |
