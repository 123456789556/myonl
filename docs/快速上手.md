# 快速上手（装上就能用）

> 目标：从零到「改一句台词 → 预览 → 导出一个别人能打开玩的成品」。
> 不需要懂编程，会改文本就行。手机是主出口；电脑端只在要做视频/镜头类演出、打 APK、跑测试时才用，见文末指路。

## 1. 拿到并装上

**手机 / 平板（推荐）**

1. 在仓库 Releases 页下载最新那个 `MYONL-v*.apk`（安卓 7.0 以上，手机和安卓平板同一个包；版本号见 README 顶部的 Release 徽章）。
2. 装上打开就是作品书架，底栏中间那个蓝圆「＋」就是新建。
3. 想先知道这东西怎么写：底栏第二格「教程」打开抽屉，最上面「建一份练习（可删）」，点一下会真的建一份短作品，四幕、带分支，能直接改；不想要就删。

**电脑浏览器（不装东西）**

- 用别人导出的单文件 `.html`，双击在浏览器里就能玩；自己在电脑上编，见 [开发者使用指南](desktop/开发者使用指南.md)。

> 不做 iOS。安卓之外，玩家侧只要有现代浏览器就能打开单文件成品。

## 2. 五步做出第一幕

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| 1 | 新建作品，打开剧本编辑区 | 书架「＋ 新建作品」 |
| 2 | 把示例台词改成你自己的话，一行一句 | 中间编辑区 |
| 3 | 保存，右侧预览自动刷新 | 保存按钮 / 自动保存 |
| 4 | 放一张背景图、一句角色台词（写法见下） | 底部「素材」页签 |
| 5 | 底部「导出」，得到一个自包含 `.html` | 「导出」页签 |

导出的 `.html` 把播放器、剧本、素材全内联在一个文件里：发微信、发 QQ、传电脑，对方用浏览器打开就能玩，不用装引擎、不用联网、不用起服务器。
安卓上导出后可直接「发给朋友」；别人发来的作品文件，也可用本应用「打开」导入（这两条壳内入口尚未在真机编译验证，以 CI 出包实测为准）。

## 3. 写第一句剧本

每行一条指令，`@` 开头；不写 `@` 的普通行就是台词。

| 想做的事 | 写法 |
|---|---|
| 换背景 | `@bg 教室`（图片放素材库，名字对应） |
| 放音乐 | `@music bgm_night` |
| 角色说话 | `@[林晚] 你还不走？`（方括号标角色，不需要先登记） |
| 旁白 | `@ 晚风很轻。` |
| 分支选项 | `@choice:` 下一行缩进写 `> 选项文字 -> 标签名` |
| 改数值 / 判断 | `@set 好感 += 1` / `@if 好感 >= 3:` 下缩进写台词 |

完整指令表见 [engine_spec.md](engine_spec.md)；素材怎么放、怎么批量导入见 [素材导入指南](素材导入指南.md)。

## 4. 手机上做不到的事（别在手机上硬撑）

手机端解析器没有实现 `@plug` `@include`：`@plug` 这台设备没有插件、成品也不演；`@include` 是电脑端多文件写法，手机单文件用不上，这行可以删掉。写到这两条行会明确报错并指出第几行，不会静默吞掉。要拆多文件剧本、打 APK、跑测试，走电脑端。完整边界见 [手机端编游戏](mobile/手机端编游戏.md)。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 预览出现红字 / 占位色块 | 剧本引用的素材不存在：检查素材名与大小写是否一致 |
| 导出的文件特别大 | 素材内联成 base64 会再胖约三分之一；超 40 MB 会提醒，超 80 MB 大概率白屏，先缩图或拆章 |
| 想在电脑上接着编 / 打 APK | 见 [开发者使用指南](desktop/开发者使用指南.md) 与 [打包使用指南](desktop/打包使用指南.md) |
