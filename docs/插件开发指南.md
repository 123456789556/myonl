# 插件开发指南（@plug: 指令扩展）
> 版本：v1.0　日期：2026-10-26　状态：✅ 已定稿

MYONL 支持**插件指令**：不修改引擎任何核心代码，把一个 Python 文件放进剧本目录的
`plugins/` 文件夹，注册一个新指令，剧本里就能用 `@plug:指令名 参数` 调用它。

适合做的事：屏幕震动、成就系统、自定义演出、与外部数据联动……任何 `@set`/`@show`
表达不了的自定义行为。

---

## 1. 五分钟上手

目录结构（插件放在**你的游戏剧本所在目录**的 `plugins/` 下，不是引擎目录）：

```
我的游戏/
├── script.gal          # 剧本
├── images/ audio/      # 资源
└── plugins/
    └── shake.py        # 插件：注册 @plug:shake
```

`plugins/shake.py`：

```python
from engine.runtime import register_command

def shake(state, args):
    # state 是真实 GameState（全权限，直接读写）
    # args 是字符串列表：@plug:shake 1.0 → args == ["1.0"]
    state["shake"] = {"power": float(args[0]) if args else 1.0}
    # 返回 dict → 作为事件进 trace（建议 type 用 "plug:指令名" 形式）
    return {"type": "plug:shake", "power": state["shake"]["power"]}

register_command("shake", shake)   # 模块顶层注册，加载即生效
```

剧本里调用：

```
@label start
@plug:shake 1.0
@ 林晚 刚才屏幕是不是晃了一下！
@end
```

跑起来：`python -m engine.demo 我的游戏/script.gal`——`load()` 会自动扫描
`plugins/` 并加载，`@plug:shake 1.0` 就能用了。**放进去就能用，零配置。**

## 2. 注册表接口（engine/runtime.py）

```python
register_command(name: str, handler) -> None
```

- `name`：指令名（中英文/数字/下划线），剧本里写 `@plug:name ...`
- `handler`：`handler(state, args) -> dict | None`
  - `state`：GameState（见 engine_spec.md 5.1 节），**直接改它就生效**
  - `args`：`@plug:` 后面的参数，按空格切分的**字符串列表**（类型转换插件自己做）
  - 返回 `dict` → 作为事件进 trace（自动附 `seq`，引擎会补 `line` 字段）
  - 返回 `None` → 静默执行（只改 state，不产生事件，同一 step 内继续下一条）
- 同名重复注册 → **覆盖**，后注册生效（plugins/ 目录按文件名排序加载）

## 3. 语义细节

| 场景 | 行为 |
|---|---|
| 加载时机 | 每次 `load()` / 读档（`load_save`）都会**清空注册表重扫** plugins/——换插件后重新 load 即生效，无需重启进程 |
| 插件语法错误/顶层异常 | 打印 `[插件警告] 加载 plugins/xxx.py 失败：原因` 到 stderr，**不崩**，继续加载其余插件 |
| 剧本用了未注册的 `@plug:xxx` | 抛 RuntimeError（中文，提示检查 plugins/ 目录） |
| handler 执行中抛异常 | 打印 `[插件错误] @plug:xxx 执行失败：原因` 到 stderr，trace 记 `{"type":"plug:error","plugin":"xxx"}`，**游戏继续**（一个坏插件不能卡死游戏） |
| 无参数调用 | `@plug:xxx` → `args == []`，合法 |
| 插件往 state 加的字段 | 随存档一起序列化，读档自动还原（GameState 深拷贝机制，无需特殊处理） |

## 4. 更多示例

**静默插件（只改状态，不发事件）**：

```python
def add_achievement(state, args):
    state.setdefault("achievements", []).append(args[0] if args else "未知成就")
    return None                      # 返回 None：不进 trace

register_command("achievement", add_achievement)
```

**读变量做条件演出**：

```python
def rain_if_sad(state, args):
    if state["vars"].get("心情", 0) < 0:
        state["bg"] = "rainy"
        return {"type": "plug:rain", "bg": "rainy"}
    return None

register_command("rain_if_sad", rain_if_sad)
```

完整可运行的样例见 `tests/fixtures/插件示例/`（剧本 + plugins/shake.py）。

## 5. 安全提示（重要）

**插件是 Python 代码 = 全权限。** handler 能读写 GameState，也能读写文件、访问网络——
Python 能做的一切它都能做。这不是缺陷，是离线引擎的设计选择（与 Ren'Py 的 python 块一致）。

- **只装可信插件**：只把你自己写的、或你完全信任来源的 .py 放进 plugins/
- 不要把来路不明的"插件包"解压进游戏目录
- 引擎**不做**沙箱隔离、插件市场、远程下载、热加载（改插件后重新 load/重启生效）

## 6. 调试技巧

- 插件加载失败看 stderr 的 `[插件警告]`；执行失败看 `[插件错误]`
- `@plug:xxx` 报"未注册"→ 检查：plugins/ 目录是否在**剧本所在目录**下、文件名是否 .py、
  模块顶层是否真的调了 `register_command("xxx", ...)`
- trace 里插件事件的 `line` 字段可定位到剧本行号
