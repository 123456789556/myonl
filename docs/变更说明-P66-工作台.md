# P66：手机端「工作台」——打开先是作品，不是 IDE

## 问题
P65 把手机端编辑器收成"一行顶栏 + 五个 tab"，但**打开就是编辑器**：一个新用户进来先看见 `script.gal` 的源码、行号、语法色、引导卡片，第一反应是"这是给程序员用的"。而且没有出口——进去以后没有按钮回"我的项目"，只能关掉页面。

## 改法：手机上先给一层"我的作品"

```
打开 ──▶ 工作台（工程卡片列表）
              │ 点一张卡
              ▼
         编辑器（P65 的五个 tab）
              │ 顶栏「‹ 作品」
              ▼
           回到工作台
```

### 后端（`engine/editor.py`）
| 路由 | 作用 |
|---|---|
| `GET /api/home` | 列出 `games/` 下所有带 `script.gal` 的工程：条数（只数 `@` 开头的行）、素材数（`images/audio/fonts/video` 下文件总数）、脚本修改时间，按时间倒序 |
| `POST /api/project` | `{folder}` 切当前工程（改 `project_root / script_path / data_root`），成功即重启会话内的工程状态 |

安全：只认 `games/` 的**直接子目录名**。`..`、`.`、空、含 `/` 或 `\` 一律 400，另有 `realpath` 父目录校验兜底（`甲/../乙` 这种绕路写法也挡住）。

### 前端（新文件 `editor/editor_home.js`）
- 只在窄屏（`max-width:860px`）接管；宽屏（桌面）完全不介入，仍是原来的三列编辑器。
- 用 `sessionStorage["myonl:editing"]` 记住"已经在编辑"，此时不弹工作台；顶栏「‹ 作品」清掉标记后重载，退回卡片列表。
- 卡片：工程名 + `49 条指令 · 21 个素材 · 11 天前` + 右侧 `›`；底部虚线「＋ 新建作品」；页脚一行"本地作品 · 不上传云端"。
- 顶部右上齿轮进**设置**弹层（底部升起，不是全屏弹窗）：界面深色/浅色分段切换、返回作品列表、一行隐私说明。

### 顺带修掉的坑
编辑器的全局 `button { height: 28px; background: var(--blue) }`（给工具条用的）会把工作台卡片也压成 28px 高、名字和副标题叠在一起。给 `.m-home-card` 等显式写回 `height: auto / min-height: 62px` 才正常。

## 验证
- 390×844 两版截图：`p65-home-dark.png`、`p65-home-light.png`、`p65-set.png`（设置弹层）、`p65-enter.png`（点卡片进编辑器，顶栏有 `‹`）。
- `/api/home` 实测返回 5 个工程（标准示例 49 条 / 21 素材、新游戏模板 15 / 21、新游戏 15 / 22、教程示例 26 / 6、newbie_demo 15 / 4）。
- 新测试 `test_工作台_列出工程并拒绝越界切换`：造 `games/甲`、`games/乙`，断言条数与素材数、切换后 `current == "甲"`、四种非法 folder 全部 400。
- 全量 `1084 passed + 1 skipped, 32 deselected`。
