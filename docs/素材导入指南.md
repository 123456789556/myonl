# 素材导入指南（批量照片 / 短视频）

> 适用：一次几十上百张照片 + 若干短视频，想把它们变成引擎能用的素材。
> 工具：`tools/import_assets.py`（依赖见 `requirements-dev.txt`：Pillow / PyAV）。
> 手机上零星选图、从相册或别的 App 分享进来，不用这个工具，直接在编辑器素材页操作即可，
> 见 [手机端编游戏](mobile/手机端编游戏.md)。

## 一条命令

```powershell
# 照片 → 背景（默认：cover 裁切到画布尺寸、存 JPG、名字加 bg_ 前缀）
py -3 tools/import_assets.py <照片目录> --project games/我的游戏

# 短视频 → @video 帧序列（默认 30fps、每个最多 10 秒）
py -3 tools/import_assets.py <短视频目录> --project games/我的游戏 --no-images

# 立绘：透明 PNG、按高度缩放、名字加角色前缀
py -3 tools/import_assets.py <立绘目录> --project games/我的游戏 --kind sprite --format png --prefix 林晚_
```

先用 `--dry-run` 看会导入什么、不会落盘。

## 它做了什么

| 步骤 | 规则 |
|---|---|
| 尺寸/适配 | `--fit auto`（默认）：**横屏素材 cover 裁切**；**竖屏/方形（抖音 9:16 等）模糊填充**——背景用同图放大模糊压暗、前景完整居中，不裁掉大半也不留黑边。也可强制 `cover / contain / blur` |
| 立绘 | `--kind sprite`：按画布高度等比缩放，保留透明通道，存 PNG |
| 命名 | 非法字符/空格 → `_`，自动加 `--prefix`（背景默认 `bg_`） |
| 去重 | 按文件内容 SHA1：同内容只导一份，其余记为 skipped |
| 冲突 | 同名默认改名（`_2`、`_3`…）；也可 `--on-conflict skip/overwrite` |
| 短视频 | 解码为 `images/videos/<名>_001.png` 起连号帧，`@video 名 fps=` 直接可用；fps 按实际抽帧反算，片段太长可用 `--max-seconds`；竖屏视频同样走模糊填充 |

## 产物

| 文件 | 用途 |
|---|---|
| `import_report.json` | 每个文件的源/目标/哈希/状态（ok / skipped / error） |
| `asset_manifest.json` | 素材清单（名字/类型/文件/字节/哈希），给打包与版本管理用 |
| `import_snippets.gal` | 可直接粘进 `script.gal` 的 `@bg` / `@video` 引用 |

## 素材格式与位置

| 类型 | 目录 | 认的格式 |
|---|---|---|
| 背景 / 立绘 / 前景 / CG | `images/` | `.png` `.jpg` `.jpeg` `.webp` |
| 音乐 / 音效 / 配音 | `audio/` | `.ogg` `.mp3` `.wav` |
| 帧序列视频 | `images/videos/` | `.png` `.webp`，`<名>_001.png` 起连号 |
| 真视频文件 | `videos/` | `.mp4` `.webm` `.mov`，配 `@video 名 file` |
| 字体 | `fonts/` | `.ttf` `.ttc` `.otf`（可选；不放则自动找系统中文字体） |

剧本里引用素材用**名字**（不含扩展名），引擎按上面的格式依次回退查找。

## 注意

1. 导入工具会自动转成引擎认的格式；剧本引用名就是文件名（不含扩展名）。
2. 短视频两条路：**导入期转帧**（`images/videos/`，几秒到十几秒的短镜头，`tools/video2frames.py` 也能单条转）；
   **运行时真视频**（`videos/` 放 `.mp4/.webm/.mov`，`@video 名 file`），适合需要原声或长一点的片段。
3. 照片建议先自己挑一遍：工具只做尺寸/命名/去重，不做「这张能不能用」的内容判断。
4. 导入后打开编辑器，右侧预览能直接看到；缺素材时状态条会提示第几行缺哪张图。
