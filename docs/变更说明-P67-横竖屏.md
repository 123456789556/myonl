# P67：横屏也算手机——方向由作者在设置里定

## 一、横屏不再跌回桌面三列

原来的窄屏判定只有一条 `max-width: 860px`。手机竖着是 390 宽，横过来是 **844 宽 / 390 高**——宽度过了 860 的门槛附近，直接掉回桌面那套三列 IDE，比竖屏更没法用。

改法：判定条件统一成 **「窄，或者矮」**

```css
@media (max-width: 860px), (max-height: 520px) { ... }
```

JS 侧四处同步（`editor_shell.js` 的 `mobileMQ`、`editor_main.js` 的相机入口与引导文案、`editor_home.js` 的接管判定）。现在手机横过来仍然是「一行顶栏 + 底部五个 tab」，不是三列。

横屏的工作台再补一条：卡片排**两列**（844 宽一列会拉成横条），标题降一档字号。

## 二、设置里加「游戏画面」

设置弹层（右上齿轮）现在是：

| 项 | 值 |
|---|---|
| 界面 | 深色 / 浅色 |
| **游戏画面** | **跟随 / 竖屏 / 横屏** |
| 作品列表 | 返回 |

这一项写的**不是编辑器的方向，是作品的**：存进工程 `config.json` 顶层 `orientation`（`any` / `portrait` / `landscape`），跟着工程走，换机也带走。

接口：
- `GET /api/orientation` 读当前工程
- `POST /api/orientation` `{orientation}` 写回 `config.json`（白名单三值，其余一律 400）

## 三、导出的网页会告诉玩家怎么拿手机

`build_web` / `build_single` 都把方向写进 `<meta name="myonl-orientation">`；播放器读到后，**方向不符就在底部浮一条提示**：

- 「这个作品是竖屏的 · 把手机竖过来 ↕」
- 「这个作品是横屏的 · 把手机横过来 ↔」

转对了提示自己消失，不阻塞、不硬锁（网页锁方向要全屏权限，各家浏览器不一致，硬锁反而会失败）。

## 踩坑：`--script` 启动时 `project_root` 不是剧本目录

第一版把方向写进 `app.project_root`，结果 `config.json` 落到了**仓库根目录**（`MYONL引擎/config.json`，35 字节，只有 `orientation`），工程自己的配置一点没动。原因：`--script games\教程示例\script.gal` 只换剧本文件，`project_root` 仍是启动时的当前目录。

修法：新增 `_current_project_root()` = **剧本所在目录**，`_home` 的 `current` 与方向读写全走它。那个误生成的根目录 `config.json` 已删。
