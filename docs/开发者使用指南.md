## 一、产品设计介绍（30 秒看完）

**MYONL 是什么**：完全离线、MIT 开源的视觉小说引擎——写剧本 → 自动变成能玩的游戏 → 打包成独立应用发给玩家（P10 规划中），玩家下载双击即玩，零配置。

**产品四层**：

```
创作者工具（编辑器）→ 引擎核心（解析/执行/渲染/存档/插件）→ 玩家体验 → 打包发布
```

**设计铁律**：
- 完全离线，断网可用；MIT 开源、不盈利、不抄袭
- 语法极简（13 条指令 + 1 个插件前缀），比 Ren'Py 简单一个量级
- 引擎不内置 AI，但留了控制原语——任何 AI 都能驱动它

## 二、快速开始（10 分钟跑通第一个剧本）

### 1. 环境要求

```
Python 3.8+    pygame-ce（渲染）   pytest（测试，可选）
```

```powershell
pip install pygame-ce pytest
```

### 2. 建一个游戏目录，写第一个剧本

```
我的游戏/
├─ script.gal          ← 剧本入口（文件名随意，路径对就行）
├─ images/             ← 背景/立绘图（png/jpg 直读，零转换）
├─ audio/              ← 音乐/音效
├─ fonts/              ← 中文字体（可选，不放则自动找系统字体）
├─ plugins/            ← 插件（P9，可选）
└─ saves/              ← 存档（运行时自动生成）
```

`script.gal` 内容（每条指令一行，`@` 开头）：

```
@character 林晚 #ffcccc        # 登记角色（名字+头像颜色）
@bg classroom                  # 换背景（images/classroom.png）
@music bgm_night               # 放音乐（audio/bgm_night.ogg）
@show 林晚 smile               # 林晚立绘上场（images/林晚_smile.png）
@ 林晚 你来了。                # 说一句台词
@ 晚上好，欢迎光临。           # 没角色名 = 旁白
@choice:                       # 选项（单独一行 + 冒号）
    > 打招呼 -> greet          # 选项文本 -> 跳转目标
    > 沉默                    # 无跳转 = 选项结束（可选）
@label greet                   # 给位置贴标签
@jump greet                    # 跳回标签
@set 好感 += 1                 # 变量加减（+= -= =，支持小数/负数/中文名）
@if 好感 >= 3:                 # 条件分支（缩进块，4 空格）
    @ 林晚 我们很熟了。
@sfx door_open                 # 播一次音效
@hide 林晚                     # 立绘撤下
@end                           # 结束，回标题
```

> 常用指令速查见第四节；全量 24 条见 [engine_spec.md](engine_spec.md) §2。注释：`#` 开头（中文注释也支持）。

### 3. 跑起来

```powershell
# 在游戏目录里执行：
python -m engine.demo script.gal          # 开窗口玩（能存档/读档/菜单/回看）
python -m engine.demo script.gal --max-frames 200   # 自动跑 200 帧（无交互，测试用）
```

按 Esc 呼出菜单，↑↓ 选择，Enter 确认。窗口 1280×720。

## 三、三种开发方式（从快到爽）

| 方式 | 工具 | 适合 | 状态 |
|---|---|---|---|
| **A. 文本直写** | 任意编辑器 + CLI 检查 | 快速、可 git 版本控制 | ✅ 全阶段可用 |
| **B. 多文件 Web 编辑器**（P7+P17） | 浏览器所见即所得 | 边写边看画面 + 多文件工程 | ✅ 已交付 |
| **C. 卡片视图**（P8） | 点卡片填表 | 零语法基础（多文件跨文件只读） | ✅ 已交付 |
| **D. 素材创作台**（P12） | 编辑器右侧素材栏 | 拖放导入 + 拖拽式补全 | ✅ 已交付 |
| **E. 桌面编辑器**（P20） | 双击 `editor.exe` | 不依赖浏览器、拖拽导入、设置与工程跟随 | ✅ 已交付 |

### 方式 A：CLI 检查

```powershell
python -m engine.cli --check script.gal     # 语法检查，错误带"文件 第 N 行"
python -m engine.cli --tojson script.gal    # 剧本 → 指令 JSON（调试/给 AI 看）
python -m engine.cli --fromjson out.json    # 指令 JSON → .gal 文本（AI 生成的剧本还原）
```

### 方式 B：多文件 Web 编辑器（P7 + P17）

```powershell
python -m engine.editor --project .            # 打开整个工程（自动递归发现所有 .gal）
python -m engine.editor --project . --port 8127  # 换端口
# 浏览器打开 http://127.0.0.1:8127
```

**P7 基础功能**（一直有）：左边写剧本右边实时预览（0.5 秒内刷新）、语法错误行内标红并自动跳转、敲 `@` 自动补全指令、一键弹窗试玩、JSON 视图调试。

**P17 多文件工程新增**：

- **文件树侧栏**：左边 220px 侧栏，递归列出工程下全部 `.gal`（自动过滤 `.hidden/` / `__pycache__/`）；支持折叠目录、显示脏文件黄点、点击切换文件（自动保存当前 buffer、免网络请求）
- **章节大纲**：侧栏下半部跨文件收集全部 `@label`（带文件名+行号）和 `@jump` 目标映射到"所在文件 / 本文件 / 未定义"；点击跳转到目标文件对应行
- **@include 行跳转**：源码中被 include 的行自动加**蓝色下划线指针**样式（`.ln.inc`），点击直接跳到被包含文件对应行
- **新建章节**：顶栏「＋ 章节」按钮 → 弹中文弹窗 → 创建骨架文件（带 `@label 章节名`）→ 自动切换到新文件
- **保存前语法校验**：顶栏「💾 保存」按钮或 Ctrl+S，保存前先校验语法，坏语法拒绝落盘 + 红字提示行号 + 自动切回源码视图并跳转；未保存离开页面前浏览器原生拦截
- **场景面板**：光标在哪一行，右侧实时显示**当前行引用的场景素材**（bg / 立绘 / 音乐 chip 化），缺素材红字「（缺素材）」，300ms 防抖不闪
- **场景时间线**：右侧下方四泳道时间线（背景 / 立绘 / 音频 / 选项），按时序展示整文件全部 bg/show/music/sfx/voice/video/choice 节点，点击节点跳转到源码对应行
- **浏览器缓存修复**：编辑器全部 API 加 `Cache-Control: no-store`，前端 fetch 带 `{cache:"no-store"}` —— 再也拿不到旧内容

> **核心规则**：check/preview/run/timeline/scene 五个 API 都带 `path` 参数，编辑器把文本当作"path 指定文件"在其目录下解析（`_parse_rel(text, root, rel)`），解决多文件 include 基准与错误定位问题。

### 方式 C：卡片视图（P8，多文件跨文件只读）

三视图切换（源码 / JSON / 卡片）。卡片视图把剧本变成一张张卡片：点卡片填表单（选角色、填台词、选跳转标签），新增/删除/排序点按钮——**不记语法也能做完整游戏**。跳转目标自动下拉收集剧本里的 `@label`，不存在的标签会标"（不存在）"警告。

**跨文件剧本注意**（P17 补充）：检测到剧本含 `@include` 时卡片视图自动降级为**只读总览**模式——顶部黄色提示条"跨文件剧本：卡片视图为只读总览，源码视图编辑保存"，指令按**源文件**分组（插 `.card-file-head` 分组头「📄 章节/第一章.gal（经 @include 展开）」），点击卡片跳转到源文件对应行。编辑保存请切回**源码视图**。

### 方式 D：素材创作台（P12）

编辑器右侧有**素材栏**（图片 / 音频 / 字体 / 视频 / 动画五类），三件核心操作：

1. **看素材**：缩略图网格，音频带 ▶ 试听；缺素材时底部红字状态条列出"第 N 行 @bg 缺 images/xxx.png"，点击跳转
2. **导素材**：把图片/音频文件拖进素材栏 → 自动归档到 images/audio/fonts → 立刻可用；也有"＋导入"按钮（系统文件选择器，可多选）
3. **拖进代码**：把素材拖到左侧代码区 → 弹浮层选指令 → 自动生成 `@bg 名` / `@music 名` / `@voice 名` 等行插入光标处

写指令时补全会列出**现有素材名**：`@bg ` 补图片、`@voice ` 补配音、`@show 角色 ` 补表情——素材从"文件夹里的文件"变成"编辑器里的选项"，全程不碰文件夹。

**P20 导入增强**：
- 同名素材弹**覆盖 / 改名 / 取消**三选（改名自动存为 `名字_1`）
- 导入完成后**自动在光标处生成指令**（图片弹 `@bg` / `@cg` / `@show` 小菜单），可在「⚙ 设置」里关闭
- 右下角 toast 中文提示「已导入 images/xx.png」

> 边界：素材由创作者自己准备（引擎不内置素材包）；导入只归档不转换（视频抽帧走 `tools/video2frames.py`）。

### 方式 E：桌面编辑器（P20，不依赖浏览器）

**打包**：双击 `build_editor.bat`（或 `py -m PyInstaller --noconfirm --clean editor.spec`）→ 生成 `dist/editor/editor.exe`。

**使用**：双击 `dist/editor/editor.exe` 打开内置窗口（1280×800），无需安装浏览器。窗口用系统 **Edge WebView2**（Win10/11 自带；老系统需装 Evergreen runtime）。命令行模式不受影响，仍可：

```powershell
py -m engine.editor --project . --port 8127     # 浏览器模式（保留）
py -m engine.editor_app --project .             # 桌面窗口模式（源码运行）
```

**⚙ 设置**（顶栏按钮）：

- **工程目录**：显示/切换当前工程；切换后文件树与剧本自动重载
- **数据目录**：留空 = 随工程（推荐）；填绝对路径 = 素材库放到工程外（移动工程后需重设）
- **导入素材后自动生成指令**：开关

**移动工程 = 复制整个文件夹**：剧本、素材、存档、`.editor_config.json` 全在工程内，配置用相对路径（`last_project: "."`），移动/改名后照常打开，无需重配。只有"数据目录"填过绝对路径时才需要回来重设。

## 四、剧本语言速查（常用指令；全量 24 条见 engine_spec）

| 指令 | 写法 | 作用 |
|---|---|---|
| 角色 | `@character 林晚 #ffcccc` | 登记角色（颜色=头像/名字颜色） |
| 背景 | `@bg classroom` | 换背景 images/classroom.png，淡入 |
| 音乐 | `@music bgm_night` | 播放/切换音乐（循环） |
| 音效 | `@sfx door_open` | 播一次音效 |
| 立绘 | `@show 林晚 smile` | 立绘上场（images/林晚_smile.png） |
| 隐藏 | `@hide 林晚` | 立绘撤下 |
| 台词 | `@[林晚] 你来了。` / `@ 晚风很轻。` | 方括号=角色台词（不需要先登记）；`@` + 空格=旁白；旧写法 `@ 已登记角色 文本` 仍有效 |
| 整屏独白 | `@[[林晚]] 很长的一段话……` / `@[[整段旁白]]` | 双括号=NVL 整屏文字，适合心理描写 |
| 选项 | `@choice:` + 缩进 `> 文本 -> 标签` | 玩家选择后跳转 |
| 标签 | `@label greet` | 给位置命名（跳转目标/存档锚点） |
| 跳转 | `@jump greet` | 跳到标签 |
| 条件 | `@if 好感 >= 3:` + 缩进块 | 条件成立才执行块内指令（`>=`/`==`） |
| 变量 | `@set 好感 += 1` | 变量运算（`+=` `-=` `=`） |
| 结束 | `@end` | 结束游戏回标题 |
| 多文件 | `@include 章节/第一章.gal` | 拆章（只允许顶层，相对当前文件目录，禁循环引用）。编辑器里被 include 的行显示**蓝下划线可点击**，直接跳到被包含文件对应行（P17） |
| 插件 | `@plug:shake 1.0` | 调用插件指令（P9，见第七节） |

**完整示例剧本**（`tests/fixtures/基础流程.gal` 同款）：

```
@character 林晚 #ffcccc
@character 苏晨 #aaccff
@bg classroom
@music bgm_night
@show 林晚 smile
@[林晚] 你来了。
@[苏晨] 嗯，等我一下。
@choice:
    > 打招呼 -> greet
    > 不理她 -> ignore
@label greet
@set 好感 += 1
@if 好感 >= 1:
    @[林晚] 你已经很信任我了。
    @jump done
@label ignore
@[林晚] 好吧……
@label done
@[[苏晨]] 今天先这样吧。   # 整屏独白示例
@end
```

**台词富文本标记（P46，像 Word 一样给局部文字排版）**

台词和旁白里可以插标记，只影响被包住的那几个字，**折行/分页仍按纯文本算**（老剧本版式零变化）：

| 标记 | 效果 | 示例 |
|---|---|---|
| `{b}…{/b}` | 粗体 | `@ 林晚 这件事{b}绝对不能{/b}说出去。` |
| `{i}…{/i}` | 斜体 | `@ 她{i}好像{/i}在看我。` |
| `{color=颜色}…{/color}` | 变色 | `{color=#ff6666}危险{/color}` 或 `{color=red}…{/color}` |
| `{size=字号}…{/size}` | 变大字 | `{size=40}不——！{/size}`（8~128px） |

规则：标记可嵌套（`{b}{color=red}又粗又红{/color}{/b}`）；没写闭合标签自动补到行尾；不认识的标签原样显示、不崩；想写字面花括号用 `{{` 和 `}}`。打字机逐字显示按**看得见的字**计数（标记不占字数）。编辑器源码区上方有 **B / I / 颜色 / 字号** 工具栏：选中文字点按钮自动包标记。

**在台词里显示变量值**：写 `${变量}`，例如 `@ 好感度是 ${好感}。`（未定义会警告并置空）。旧写法 `{变量}` 仍可用，但只替换**已定义**的变量，且 `{b}` / `{i}` / `{color=…}` / `{size=…}` 这些富文本标记不会被当成变量吃掉。

**界面主题与正文对齐（P46，三套模板直接套用）**

新建游戏时选主题与对齐，建完随时在 `config.json` 改：

```
py -m engine.new 我的游戏 --align center
```

| 选项 | 取值 | 效果 |
|---|---|---|
| `--theme` | `black`（唯一标准版） | 只有一套标准版 UI；想换配色直接改 config.json 的 theme/colors |
| `--align` | `left`（默认）/ `center` / `right` | 正文台词对齐：左顶格 / 居中 / 右顶格 |

- 主题实际写入 `config.json` 的 `theme` + `colors` 段（紫/白 = 在黑配置上做增量覆盖），想自己换肤就改里面的 RGB 颜色数组
- 对齐写入 `dialogue.default.align` 与 `dialogue.nvl.align`（对话框 / NVL 全屏两种模式各自一份）；填了非法值按 `left` 处理，不崩
- 旁白与角色台词同一规范，不做专门区分；标题开场文字保持电影式居中，不受该配置影响
- Web 编辑器「新建游戏」弹窗里有对应的「界面主题 / 正文对齐」下拉，与 CLI 等价

## 五、存档机制（开发者要懂的底层）

**存档不存"第几行"，存"离哪个标签往后数几句"**：

```
存档 = { 剧本路径, 变量表, 立绘/背景/音乐, 对话历史, 锚点栈: [("greet", 3), ...] }
```

读档时重新解析剧本 → 找到标签 → 往后数对应句数 → 恢复现场。所以：**剧本小改、加新章节，旧存档依然有效**；改了剧本结构导致锚点找不到时，引擎抛中文错误并钳制到安全位置，不会崩。

- 10 个存档位（1~10，数字键 0 直达第 10 格）+ 1 个快存位（quick，F5）
- 存档目录 `saves/`，JSON 格式，可直接打开看；`settings.json` 的 `data_dir` 可切到 AppData 或自定义绝对路径
- 存档带版本号（SCHEMA_VERSION=4），未来改格式走 MIGRATIONS 迁移表，旧存档自动升级

## 六、多文件组织（长剧本拆章）

```
主剧本.gal：
    @include 章节/第一章.gal
    @include 章节/第二章.gal
    @label main_end
    @end
```

规则：
- `@include` 只允许顶层（无缩进）；路径**相对当前文件所在目录**
- 禁止循环引用（A 引 B、B 引 A → 报错）
- label/角色是全局命名空间（和 Ren'Py 一致）；报错精确到"子文件 第 N 行"
- **`@jump` 可跳到 `@include` 过的其他文件的 `@label`**：运行时用 include 展开后的全局标签表，跨文件跳转可直接跑通。注意跳过去后按该文件段落继续执行，**不会自动跳回**原文件；想回来就在目标段落末尾再写一个 `@jump`。
- 编辑器单文件打开子文件时，`@jump` 的目标若只在别的文件里，静态检查可能提示"目标不存在"——这是编辑器的单文件校验限制，运行时不受影响；用主文件（含 `@include` 的那个）整体检查/运行即可。

## 七、插件开发（P9，扩展引擎能力）

想加引擎没有的能力（屏幕震动、成就系统、自定义演出）？写一个插件，**不用碰引擎核心**：

```python
# plugins/shake.py —— 示例插件：@plug:shake 1.0
from engine.runtime import register_command

def shake(state, args):
    # state 是真实 GameState（全权限，可加自定义字段，随存档保存）
    state["shake"] = {"power": float(args[0]) if args else 1.0}
    return {"type": "plug:shake", "power": state["shake"]["power"]}
    # 返回 dict → 进对话历史（trace）；返回 None → 静默（只改状态）

register_command("shake", shake)
```

用法：

```
@plug:shake 1.0
```

规则：
- 插件放**剧本所在目录的 `plugins/`**，`runtime.load()` 自动扫描加载，**放进去就能用**
- handler 签名：`handler(state, args: list[str]) -> dict | None`；参数全部是字符串，自己转类型
- 安全：插件是 Python 代码 = 全权限，**只装可信插件**；坏插件不崩游戏（stderr 中文警告 + 游戏继续）
- 详见 `插件开发指南.md`

## 八、AI 协作开发（让 AI 驱动引擎）

引擎不内置 AI，但提供**控制原语**——全部 JSON 进出，任何 AI（豆包/Trae/本地模型）都能调用：

- **加载剧本 / 推进剧情 / 选择选项 / 改变量 / 注入指令 / 存档读档 / 截图 / 读取运行轨迹**
- 工作流：AI 读剧本 → 驱动引擎跑 → 看截图/轨迹 → 改剧本（`--fromjson` 把 AI 生成的指令 JSON 还原成 .gal）
- 权威接口定义见 `engine_spec.md` 第 5 节

**推荐 AI 协作流程**（本项目实测）：
1. 你定大纲，AI 写剧本初稿
2. `engine.cli --check` 语法检查，错误自动修
3. 编辑器实时预览看效果，人肉微调台词
4. 关键分支用卡片视图/JSON 视图校验结构

## 十一、常见问题

| 问题 | 答案 |
|---|---|
| 画面是灰块 | 资源缺失：检查 images/ 里的文件名与指令是否一致（大小写、扩展名） |
| 中文显示方块 | 系统没有中文字体：放一个 .ttf 到 fonts/（如 NotoSansCJK） |
| 编辑器打不开 | 端口被占：`--port 9000` 换端口；只绑 127.0.0.1，安全 |
| 旧存档报"来自更新的引擎版本" | 引擎升级了存档格式：更新引擎后读档即可（版本迁移机制兜底） |
| 插件指令报"未注册" | plugins/ 里没有该插件 / 插件加载失败（看 stderr 警告） |
| 找不到 python | 检查 `python --version`，Windows 用 `py` 或 `python3` |
