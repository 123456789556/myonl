## 电脑端常用命令速查

```powershell
# 语法检查（错误带行号）
py -3 -m engine.cli --check script.gal

# .gal ↔ 指令 JSON
py -3 -m engine.cli --tojson script.gal -o out.json
py -3 -m engine.cli --fromjson out.json

# 新建工程骨架
py -3 -m engine.cli new 我的游戏

# 跑示例（无窗口截图验证加 --max-frames）
py -3 -m engine.demo games/标准示例/script.gal --assets games/标准示例

# 打开编辑器（浏览器模式）
py -3 -m engine.editor --project games/标准示例

# 全量测试
py -3 -m pytest -q
```

> 手机端能做 / 不能做的边界，见 [手机端编游戏](../mobile/手机端编游戏.md)。
