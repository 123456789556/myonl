## 二、首次 Release 文案草稿

**MYONL v1.0.0-rc7 · Windows 离线视觉小说创作引擎（发布候选）**

MYONL 是一个完全离线、开源（MIT）的 Windows 视觉小说 / Galgame 创作引擎。创作者用中文 `.gal` 脚本写剧本，引擎负责解析、演出、分支选项、存档、CG 画廊与一键打包；内置 Web 编辑器与实时预览，源码版改剧本可热重载。

- 引擎能力：`.gal` 剧本解析、演出演出（打字机、缓动、镜头、转场、动画立绘、帧序列视频、配音）、标题/菜单/10 格存档/回看/设置/CG 画廊/快捷栏。
- 创作工具：编辑器三视图（源码 / 卡片 / 场景）+ 实时预览 + 语法检查 + 一键打包；`config.json` 外观可配置。
- 两种使用方式：发行版无需 Python（见下方 Release 附件）；源码版需 Python 3.9+（3.9 … 3.15 均实测通过）与 `pygame-ce>=2.5`。
- 质量门禁：GitHub Actions 在 `windows-latest` 上跑 3.9–3.15 版本矩阵；日常快速套件全通过，`slow` 用例（真实打包 / 性能基准 / 全渲染）由手动触发运行。
- 许可：MIT；第三方组件与素材许可见 `NOTICE`。

> rc7 为 `v1.0.0` 的候选版本；本版只做交互与失败态收口（无 DSL / 接口变更），接口与默认素材后续仍可能调整。

### rc7 增量（相对 rc6）

- **失败提示可定位**：游戏启动失败 / 热重载失败改为弹「第 N 行：原因」单行 toast（发行版无控制台）；设置写盘、存档、读档、打包失败均有中文提示，读档失败退回存档列表重选。
- **失败不留半成品**：剧本与 `config.json`、`.editor_config.json` 改为临时文件 + `os.replace` 原子替换，写盘中途失败保留上一版；模板打包失败保留上一版产物。
- **编辑器对齐与窗口缩放**：高亮层宽度对齐文本域内容区，经典滚动条下软换行断点一致（行号 / 当前行 / 错误行不再累积偏移）；窗口变矮时 Dock 重新夹紧，编辑区至少保留 300px。
- **快捷键与关闭确认**：补 F5 / Ctrl+R / Ctrl+P / Ctrl+N / Ctrl+,；桌面窗口关闭前提示未保存改动。
- **性能基线（不做优化，如实记录）**：4000 行文档单键约 42.5ms，其中 41.05ms 为 textarea 整篇重排（`updateLineNumbers` / `incSignature` / 面包屑合计 <0.4ms）；推迟读宽不减少总耗时，故本轮不改。

## 三、功能清单（以 README 与 engine_spec 为准）

- **剧本 DSL**：24 条指令（`@bg / @music / @show / @anim / @fg / @cg / @camera / @transition / @chapter / @choice / @set / @if / @jump / @voice / @video / @include` 等），中文直写；支持方括号角色台词、双括号整屏独白、旁白、变量与条件分支。
- **演出**：打字机文本、22 条缓动曲线、镜头 pan/zoom/shake、三种转场、动画立绘、帧序列视频背景、配音。
- **玩家外壳**：标题 / 菜单 / 10 格存档 / 回看 / 设置 / CG 画廊 / 快捷栏；标准版主题，`config.json` 可换肤。
- **开发体验**：Web 编辑器（源码 / 卡片 / 场景三视图）、语法检查、一键打包、剧本与配置热重载（`--hot-reload`）。
- **适配与性能**：逻辑画布可配（1280×720 / 1920×1080 等比缩放）；素材按需加载 + LRU 缓存，避免大素材库一次性占满内存。

## 四、运行方式

### 1）源码版（本仓库）

```powershell
pip install -r requirements.txt          # 唯一运行依赖：pygame-ce>=2.5
py -3 -m engine.demo games/标准示例/script.gal --assets games/标准示例
py -3 -m engine.editor --project games/标准示例   # 浏览器打开 127.0.0.1 编辑器
```

开发与质量门禁：

```powershell
py -3 -m pytest -q -m "not slow"        # 日常快跑
```

`requirements-dev.txt`（pytest / pyright / pytest-cov / Pillow / av / soundfile）仅为开发与素材工具链，**不是运行依赖**。

### 2）发行版（无需 Python）

冻结后的 `editor.exe` 与玩家运行库模板由 `tools/build_editor.bat`、`tools/build_release_zip.py` 产出，作为后续 Release 附件分发；源码仓库不包含这些构建产物。
