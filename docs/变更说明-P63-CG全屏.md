# P63 变更说明：CG 全屏、存档不串、缺图当面说

## 1. `@cg` 从来没上过手机

`@cg`（全屏一张大图，视觉小说里最有存在感的一档）在桌面端一直有。手机端有两个断点：

- 编译器 `_walk()` 只收 `bg` 和 `show`，**CG 图根本没进 assets**；
- 内核 OPS 里没有 `cg`，落到"不支持的指令"就继续往下跑；
- `unsupported` 里如实列着 `cg`——所以这不是 bug，是压根没做。

现在三处都补上：`_walk` 收 `node["name"]`；`OPS` 加 `cg`、`case "cg"` 吐 `{type:"cg", name:"..."}` 并写进 `state.cg`（进存档）；播放器 `drawCg()` 用 cover 铺满全屏，画在立绘之上、对话框之下。

语义和桌面端对齐：**`@cg` 上图 → 一直盖着 → 下一条 `@bg` 才退场**。所以作者不用记"什么时候关掉 CG"，换背景就是退出。

素材缺失时不再是一片黑：画一句"CG 素材缺失：xxx"，作者一眼知道少了哪张。

## 2. 两个游戏会互相抢存档

存档 key 原来只有标题：`myonl:auto:<标题>`。两个都叫"我的游戏"的工程，后开的那个会读到前一个的进度——轻则进度错乱，重则跳到不存在的 label 直接结束。

改成 `标题 + 剧本名 + 指令条数`。同一份工程改剧情条数后会从新的存档开始（比读到脏数据好）。

## 3. 缺素材现在会当面提示

导出接口一直返回 `missing`，前端从来没显示。作者的工程少一张图，导出去发给别人，对方看到的是一片空白——而作者以为没问题。

现在两处都提示：
- UI 设计弹窗：列表下多一行红字「⚠ 有 N 个素材找不到，游戏里会是空白：……」
- 菜单导出：toast 里补一句。

## 验证

| 项 | 结果 |
| --- | --- |
| CG 进素材表 | `pack["assets"]` 含 `cg_拥抱` |
| `unsupported` | 不再有 `cg`（`camera`/`video`/`fg`… 仍在） |
| 单文件 | 59 KB，CG 是 `data:image/png` |
| 真跑起来 | 点一次后 `cg = cg_拥抱`，左上角取色 `[200,120,140]`（粉色铺满） |
| 退场 | 下一条 `@bg` 后 `cg = ""` |
| 读档 | `state.cg` 进存档，读回来还在 |
| 门禁 | 全量 `1083 passed + 1 skipped`，vm-smoke 新增 cg 三条断言 |

## 边界

- `@video` / `@fg` / `@camera` / `@shake` / `@anim` 手机端仍未实现，会如实进 `unsupported`。`@video` 要真视频解码 + 帧率对齐，不是一晚上能稳的，不做半成品。
- CG 不做淡入淡出（桌面端有 fadein，手机端先硬切）。
