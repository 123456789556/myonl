# P74 · 手机连电脑 / 插线互传 / AI 预留 / 全身立绘

这一期回答三个问题：手机和电脑怎么在一起工作、插上线怎么把东西送过去、AI 的位置留在哪里。
顺带把「立绘要全身、要有活人的动」这件事补上。

---

## 一、先说清楚「协同」是什么

编辑器和游戏本来就是**跑在电脑上的一个 HTTP 服务**，手机只是它的浏览器客户端。
手机打开同一个地址，就是在编辑电脑磁盘上那份工程 —— 改剧本、导素材、调 UI、导出，
落点全在电脑上。所以协同不需要另做一套同步机制，缺的只是「手机怎么找到这个地址」。

这一期补的就是这个入口。

## 二、手机连接（不需要线）

`engine/mobile_link.py`：

- `local_ips()` 用 UDP connect 试探默认出口，拿到本机在局域网里的 IPv4（过滤 127.*），
  比解析 `ipconfig` 文本稳。
- `qr_data_url(text)` 用 `segno`（纯 Python，零编译依赖）把地址画成 PNG，
  返回 `data:image/png;base64,...`。**浅底深码**，深色界面上也能扫。
  没装 segno 就返回空串，前端不显示图 —— 不拦着编辑器用。
- `link_payload(port, project)` 组装给前端的全部字段。

编辑器里新增 `GET /api/mobile-link`。设置中心里那张「手机连接」卡片显示
二维码 + 地址 + 复制按钮 + 重新探测。本机实测 `http://10.20.152.240:8790/`。

## 三、插线把成品推过去

`adb_state()` / `adb_push()`（同文件）：

- adb 路径按 `MYONL_ADB` → `_tools/platform-tools/adb.exe` 找；
- `adb devices` 有超时（12s），并把 `TEMP` 指到 platform-tools 同级目录
  （某些机器上默认 `%TEMP%` 会被拒）；
- `adb_push()` 先 `shell mkdir -p /sdcard/Download/MYONL` 再 `adb push`；
- **没设备时如实报「没检测到手机：插好后打开开发者选项 → USB 调试」**，不假装成功。

编辑器里是 `GET /api/adb` 与 `POST /api/adb`（`mode=simple` 只检测）。推的目标固定
`dist/single/<工程名>.html`，推完手机用任何浏览器点开就能玩。

## 四、AI 的位置留在哪（预留）

`engine/ai.py`：配置在 **`~/.myonl/ai.json`** —— 用户目录，不进工程、不进导出包、不进 git。
一份 key 不该因为导出一次网页包就跟着发出去。

- `payload()` 只回掩码（`sk-ab...wxyz`）和 `has_key`，**任何情况下不返回明文**；
- `save()`：空 key = 沿用旧值，`clear_key:true` 才真清；`base_url` 必须 http(s)；
  `max_tokens` 夹 64–8192、`timeout` 夹 5–120；写盘用 tmp + `os.replace`，并尽力 `chmod 600`；
- `ping()` 打 `base_url + /models`，不消耗 token，只回答「连不连得上」。

设置中心里的「AI 助手（预留）」有接口地址 / 模型名 / Key 三个字段和保存、测试连接两个按钮。
**现在只把位置留好**，真正让 AI 改剧本的能力接在这后面。所有失败都回 HTTP 200 + `ok:false`，
理由是这属于「还没配好」的正常状态，不该让浏览器控制台飘红。

## 五、全身立绘 + 常驻微动

之前竖屏立绘是「按屏高 0.72 缩放、脚底贴屏幕底边」，结果下半身整段被对话框盖住 —— 等于又变回半身。

改成：

- **竖屏**：脚底贴「对话框上沿」（`L.panelY - 6`），身高上限 `min(0.86 屏高, panelY-6)`，
  头顶不会顶出屏幕，人从头到脚都在画面里；
- **横屏**：仍然贴底边（`viewH`）、身高 0.94 屏高 —— 横屏要人「大」，
  被对话框压住小腿是横屏 galgame 的标准构图。

`idleMotion()` 加了常驻微动（**不是 `@anim`，`@anim` 叠在它上面**）：

```js
breath = sin(t * 1.05 + 相位) * 0.011   // ±1.1% 纵向呼吸
sway   = sin(t * 0.58 + 相位) * 0.009   // ±0.9% 微摆（重心）
```

以脚底中心为锚先落点、再 rotate、再 scale —— 顺序决定缩放不会把脚抬离地面。
相位按槽位错开，两个角色不会像机器人一样同步。

**边界说明（重要）**：这不是 Cubism Live2D。真的 Live2D 要 `.moc3` 模型 + Cubism SDK，
后者是专有许可（有营收条款），而且需要美术按部件绑骨骼 —— 引擎是 MIT 开源，内置专有 SDK
有法律问题，也没有模型可用。这里做的是「全身立绘 + 程序化微动」，靠的是几处 1% 量级的小动作。
要更接近 Live2D，下一步是**分层立绘**（body / eyes_open / eyes_closed / mouth_*\），
引擎按层叠并驱动眨眼、说话口型 —— 那个需要作者自己出分层素材。

示例工程的立绘换成了全身图（`林晚_全身微笑.png` 368×1400、`林晚_全身生气.png` 382×1400，
透明底、按 alpha 包围盒裁到贴边），`script.gal` 里的 `@show 林晚 全身微笑` 跟着改。

## 六、顺手修的三处

1. **手机上设置中心变成窄条**：`.center-page.split` 的 `left:auto; width:56%` 特异性更高，
   抢掉了窄屏的全屏规则 → 手机上只在右侧占三分之二、左边一片空白。窄屏下强制整屏。
2. **设置分页挤压内容**：`.set-tabs` 固定 132px 竖列，390 宽的屏幕先被吃掉三分之一。
   窄屏改成顶部横排、可横向滚动。
3. **黄色/橙色退场**：编辑器里 19 处 `var(--yellow)`、3 处 `var(--peach)` 全是「提示、徽标、
   选中框、dirty 点」这类强调语义 —— 统一换冷色（黄→天空蓝、橙→紫），红色只留给真错误。

## 七、测试

`tests/test_p74_mobile_link.py`，13 条（`pytest.mark.unit`，进 `-m "not slow"` 门禁）：

- 局域网地址不含回环；
- 二维码是能被 PIL 解开的 PNG data URI，空文本不出图；
- `link_payload` 字段齐全；
- 没 adb / 没设备时 `adb_state()` / `adb_push()` 如实 `ok=False`；
- AI：默认关闭、只回掩码（断言中间段与原串都不出现在 JSON 里）、空 key 沿用、
  `clear_key` 才清、`base_url` 必须 http(s)、数值夹紧、没 key 时 ping 直接说没配、
  配置写入后能读回。

`conftest`/门禁另外踩到两条：新测试文件的 `pytestmark` 必须是**列表**（`[pytest.mark.unit]`），
不是单值；续跑全套时本机要 `OPENBLAS_NUM_THREADS=1`，否则 6% 处会
`OpenBLAS error: Memory allocation ...` 直接中断。
