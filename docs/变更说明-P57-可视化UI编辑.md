# P57 变更说明：对话框 UI 的可视化（PPT / 虚幻式）编辑

## 为什么改

之前调「圆角、位置、宽高」只能拖滑杆、看数字。数字和画面分离，调一个圆角要在脑子里换算成像素，改一次要来回看预览。参照虚幻编辑器和 PPT 的做法：**在画布上直接抓住控件拖**，数字只是结果。

## 做了什么

1. **画布上的选择框**（`editor/editor_uidesign.js`）
   - 预览图上叠加一个虚线选择框，四角 4 个 + 四边中点 2 个 × 2 = **8 个手柄**，左上角内侧一个**绿色圆点**专管圆角。
   - 标签显示当前拖的东西：`对话框面板 · 拖角改圆角`。

2. **按坐标判命中，不依赖 DOM 叠层**
   - 监听挂在 `document` 捕获阶段，用预览图的 `getBoundingClientRect()` 把鼠标位置换算回画布坐标，再拿面板矩形判区。
   - 命中规则：边/角附近 14px 命中带；左上角 34px 内算圆角点；框内其余位置算"整体移动"；框外一律放行（保留原来的点图放大）。
   - 这样绕开了「手柄被图片/裁剪区吃掉点击」的问题：位置对了就一定能拖，不要求精准戳中 12px 的小方块。

3. **拖拽分支**（`uidDragStart` / `uidDragMove`）
   - `move`：改 `offset_x / offset_y`。
   - `e` / `w`：改 `panel_width`，同时反算 `offset_x`，让**对边钉住**（拖右边不动左边）。
   - `n` / `s`：改 `height`；拖下边同时改 `offset_y`。
   - `nw / ne / sw / se`：横向按左右手柄、纵向按上下手柄，双轴一起改。
   - `radius`：直接拖绿点，改圆角（0–40）。

4. **布局前提**（`editor/editor.css` + `editor/index.html`）
   - UI 设计区在编辑区里是「中心页面」，宽度只有 ~525px，原来是表单 + 预览挤在一行，预览列被裁到 100px 左右，根本没法拖。
   - 改：`.ui-design-body{flex-wrap:wrap}`，预览列 `flex:1 1 340px; min-width:340px`，并且 **`order:-1` 让画布排到最上面**——一打开就先看到画布，参数在下面。
   - 弹窗形态下的内层盒原来被内联 `width:940px` 钉死，改成 `#uiDesignModal .modal{width:min(1180px, calc(100vw - 40px))}`。
   - 选择框改成**屏幕 px 定位**（按预览图实际渲染尺寸换算），不再用百分比：图片未加载完/容器变宽时百分比会算歪，命中判区跟着一起歪。

## 验证

真实 Chromium（playwright，视口 1360×900，直接连编辑器 HTTP 服务）：

| 操作 | 结果 |
| --- | --- |
| 拖面板本体 | `offset_x 0 → -104`，`offset_y 0 → -78` |
| 拖右边缘 | `panel_width 0（全宽） → 920`，`offset_x → -200` |
| 拖左上角绿点 | `radius 18 → 40`（预览图圆角同步变大） |
| 拖上边缘 | `height 200 → 364` |

截图：`screenshots/p57-canvas-handles.png`（选择框、8 手柄、绿点、圆角已变）。

门禁：`pytest -m "not slow"`、`node --check editor/editor_uidesign.js`、`node web/test/vm-smoke.js`、`node web/test/layout-smoke.js` 全绿。

## 边界（没做的部分）

- **只有「对话框」页签可拖**。名字框 / 选项按钮 / 快捷栏 / 菜单 / 设置页 / 配色仍然走滑杆——它们的几何键（按钮宽高、间距、名字牌位置）还没有对应的画布矩形，得先在后端把每个分组的矩形算出来，才能接同一套手柄。这是下一步。
- 拖动不跨画布边界限制：偏移滑杆本身范围是 ±200 / ±160，超出会被滑杆夹住。
- 没有撤销：拖完的值直接写进滑杆，保存仍走原来的「保存到项目配置」。
